# よく出る不具合と見分け方

見本の部屋を作ったときに実際に出た不具合。見て直す手順（SKILL.md の 8）で、まずこれを疑う。

## 形・向き

| 症状 | 原因 | 直し方 |
|---|---|---|
| 面が黒っぽい・内側から照らされたように見える・縁に黒い線 | 面の表裏が逆（法線が内向き）。輪郭を内 → 外へ上を回る回転体（器の縁）などで起きる | `flip` を足す / 外す。器の縁は輪郭の向きを確かめる |
| 寝かせた本・物が鏡写しになる | 軸を入れ替えただけ（[x, y] → [y, x]）は鏡写しで、面の向きも裏返る | 軸の入れ替えでなく回転（例: z 軸まわり −90° は (x, y) → (y, −x)）で置く |
| ラベルの正面が 90° ずれる | 回転体の u = 0 は +x。正面 +z は u = π/2 | 模様の判定を u = π/2 基準にする |
| 置き場所で模様が変わる・隣の物と模様がつながる・帯や札が出ない | 模様を部屋の座標 p で決めている（色の関数の p は置いた後の部屋の座標。`boxFaces` も同じ） | 局所の (u, v)・面の (s, t) で決める。p はむらのノイズにだけ使う |
| メッシュとスプラットで形や色が食い違う・並びがずれる | 色・位置・間引きの関数の中で乱数（`R`）を使った。メッシュの記録はこれらを粒と違う回数呼ぶので、乱数の流れがずれる | 乱数は関数の外で先に引いておき、値を閉じ込める |
| 物がまとめて 1 か所に置かれる | 置き場所をあとで変わる変数（ループの外の `let x`）で閉じ込め、あとから評価した | 曲面はその場で計算する（今の部品はそうなっている）。自分で遅らせて評価しない |
| 物が浮く・めり込む | 実寸・原点の取り違え（中心原点と底原点） | 原点の約束（底の中心）を守る。棚板の上面 = 0 で並べる |

## 粒・メッシュの作り

| 症状 | 原因 | 直し方 |
|---|---|---|
| 縦の筋・巨大な粒（スプラット） | パラメータの速さが場所で極端に変わる形（e の小さい超楕円体の赤道） | 今の部品は長さで等間隔・超楕円体は立方体の面から写すので出ない。新しい部品を足すときも同じ考え方にする。粒の大きさの最大を console で確かめる |
| 茂みが透けて向こうの壁が見える | 葉の数が足りない | 中に暗い色の芯（楕円体）を入れる |
| 小さな葉がちらつく（メッシュ） | 細かい三角形のエイリアス | 葉を減らして大きくする・芯を入れる。または茂みだけスプラットにする |
| 作成が急に遅くなる | 小さな曲面（葉など）が数千枚あり、1 枚ごとの長さの表が重い | 今の部品は曲面の大きさで表を粗くする。数を減らすか間隔を広げる |
| 粒・三角形が多すぎる | 間隔が細かすぎる・見えない面まで作っている | 見る距離で間隔を決める。棚の奥・床に接する面・本の間の表紙は作らない |

## 照明・材質

| 症状 | 原因 | 直し方 |
|---|---|---|
| スプラットが暗く沈む | GTAO（画面の遮蔽）が物の後ろの隅の陰を粒に掛ける | 物の内側に深さだけを書く箱（代役）を置く。外へはみ出すと後ろが描かれず穴になる |
| スプラットが懐中電灯で照らされない | 粒は v2 の照明を受けない | `splatMaterial.ts` の照らし直しを使う（メッシュは不要） |
| メッシュが真っ暗 | 頂点に `bakedLight` が無い（v2 の材質は焼き込み光を頂点から読む） | `bake.ts` の `bakePoints` で焼く。外から読んだ GLB も同じ |
| ガラスの奥の物にガラスが掛からない（スプラット） | 粒は透ける物の後に描かれる | メッシュにする。スプラットのままなら仕方ない |

## Blender で作るとき（比較で試したときに出た）

| 症状 | 原因 | 直し方 |
|---|---|---|
| メタボールの部位がつながらない・縮む | 見える半径は影響の半径より小さい（しきい値と硬さで決まる。しきい値 0.35・硬さ 1 で約 54%） | size = 実寸 / √(1 − (しきい値 / 硬さ)^(1/3)) |
| 1 つの塊になって形が無くなる | 硬さが低すぎてつながりすぎる | 硬さを上げる（4〜6） |
| 色の付いていない部品が黒くなる | 結合で頂点の色の無い部品が黒で埋まる。glTF は地の色 × 頂点の色 | 結合後にその部品の頂点の色を白にする |
| 頂点の色が書き出されない | 書き出しの設定 | `export_vertex_color="ACTIVE"` |

## 確かめる環境

- ブラウザのペインが隠れていると requestAnimationFrame が止まり、Worker も遅くなる（作成に数倍かかる）。撮影して前に出してから待つ
- 移動の直後は視点が追いつくまで 2〜3 秒待ってから撮る
