## Blender のスクリプトで試した結果（クマ、同じ寸法・配色）

`experiments/v2-splat-props/eval/blender_bear.py`（Blender 5.2 をコマンドで動かす）。メタボールで部位を滑らかにつなぎ、頂点の色で模様、GLB に書き出し、見本の部屋に `evalTools.ts` で同じ条件（v2 の材質・焼き込み照明）で並べた。

| | A この手法のクマ | C Blender のクマ |
|---|---|---|
| 形 | 部位の楕円体を組む。継ぎ目にしわ（くびれ）が出る | 部位が滑らかにつながる（有機的な形はこちらが上） |
| 模様 | テクスチャで、お腹・口元の境目・縫い目・布のむらがくっきり | 頂点の色で境目がぼやける（細かい模様は焼いたテクスチャが要る） |
| 三角形 | 9,572 | 26,308 |
| 配る量 | コードだけ（形は読み込み時に作る） | GLB 550 KB（無圧縮。1 種類 1 ファイル） |
| ゲームでの準備 | 55 ms（作る + 焼き込み） | 15 ms（読み込み + 焼き込み） |
| 納得できる形になるまで | （見本の部屋の作成中に数回直した） | 6 回（つながらない → 縮む → 1 つの塊 → 色がはみ出す → リボンが黒い） |
| 種類を増やす | 乱数の種と引数でいくらでも | 種類ごとに書き出し直してファイルが増える |
| 必要な道具 | ブラウザ・Node だけ | Blender（このマシンには有る。他の環境・CI には無い） |

ゲームの距離では両方ほぼ同じに見えた。近くで見ると、形のなめらかさは C、模様の細かさは A が上。

## 結論

- **標準は A（この手法）**。理由: AI が書いて画面で確かめて直す流れに最も合う / v2 の照明・材質にそのまま乗る / 種と引数で種類を増やせて、配る量はコードだけ / 決定論で作風がそろう
- **C（Blender）を使ってよい場面**: 部位が滑らかにつながる有機的な形・面取りやブーリアンが要る形で、少数の目玉の物（数を増やさない物）。そのときも `evalTools.ts` で同じ条件に置いて比べ、頂点の焼き込みと v2 の材質の注入を施す
- **A の弱点と、足すとよい部品**: 部位の継ぎ目（楕円体どうしの交わり）が硬い。メタボール・SDF のような「滑らかにつなぐ部品」を A に足せば C の利点も取り込める（まだ無い）
- **D・E は標準にしない**: 作風・陰の焼き付き・権利・配る量・種類の増やし方が v2 に合わない。参考の形を見るのには使える
- 前提: 果てしない階で数百個を置くには、遠くの段階（LOD）・同じ形の使い回しがまだ無い。量が増えたら先に用意する
