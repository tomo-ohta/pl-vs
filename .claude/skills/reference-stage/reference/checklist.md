# 読む観点・見直しの表

## 読む観点（段階 0）

画像ごとに次を書く。数値は `node tools/capture.mjs --analyze <視点>` から。

| 観点 | 書くこと | 例 |
|---|---|---|
| 構図 | 一点 / 二点透視、消失点と地平線の画素、目の高さ、見下ろす / 見上げる | 消失点 (762, 436)、目 1.25 m、少し見下ろす |
| 色 | 主な色（10 色の表）と割合、彩度、色相の帯、アクセント | セージ〜クリーム、彩度 0.02、アクセントなし |
| 明るさの段 | 平らな面か・何段か・グラデーションか（上位 16 色・平坦率） | 2〜3 段の平らな色面 |
| 境目の形 | まっすぐ / ちぎれ / 階段状 / ぼけ | 白い塗りの縁が筆でちぎったよう |
| 線 | 有無・色・太さ・どこにだけ | 物の外形と接地だけ、暗い青緑 |
| 空気 | 奥が明るい / 暗い、霧の色、空との継ぎ目 | 奥が白くかすむ |
| 光源 | 何が光るか・にじみ・色温度 | 天井の小さな白い長方形 |
| 質感 | タイル・水・濡れ・反射・粒 | 床に白い斑 |
| 小物 | 何がどこに、記号化の程度 | 左手前に箱、右に暗い棚、スイッチ |
| 矛盾 | 同じ場所の画像同士で合わない所 | 柱の位置が画像ごとに違う → どちらを優先するか |

## 見直しの表（統括が担当の結果を見るとき）

撮り直す: `node tools/capture.mjs <場所> --grid 8x4 --perf`。`-cmp.png`・`-edges.png`・`-diff.png` を必ず開く。

| 見る所 | 確かめること | 指摘の書き方の例 |
|---|---|---|
| カメラ | 消失点・地平線・主な縁が白く重なるか（`-edges.png`） | 「消失点が参考 (730, 320)・描画 (745, 300)。pitch を少し上げ、yaw を左へ」 |
| 構図 | 柱・扉・物の位置と太さ | 「左の柱: 参考 x≈200〜490、描画 70〜480。太すぎる」 |
| 足りない物・余計な物 | 輪郭の赤だけ（足りない）・水色だけ（余計） | 「右上の梁が無い（参考 x 1000〜1400, y 0〜120）」 |
| 明暗の構造 | 暗い帯・明るい帯の位置（`-diff.png` の赤・青の面） | 「上屋の下面が赤（明るすぎ）。参考は暗い青緑」 |
| 色 | 主な面の色（`--sample-both`） | 「床: 参考 #378b80、描画 #349a93。少し明るく青い」 |
| 境目・線 | ちぎれ方・線の量・点線になっていないか | 「線が点線になっている（法線の線）」 |
| 空気 | 霧の色・濃さ・奥の明るさ | 「奥の霧がシアンでなく白に寄っている」 |
| 質感 | 水・反射・タイル・草 | 「草が縦の縞で雨に見える。0.2〜0.5 m の柔らかい塊に」 |
| 歩いたとき | 視点の間の継ぎ目・箱の縁・模様の泳ぎ | 「station-3 の上屋の端の下に半透明の箱の縁（x 560 / 945）」 |
| 重さ | `--perf` で 8 ms 以下 | 「pool-1 が 10.4 ms。影の地図を毎フレーム描いている」 |
| 禁止事項 | 参考画像を読み込んで写していないか（`grep -rn "refs/\|\.jpg\|base64" src/scenes`） | 「水たまりの型を参考画像から焼いている → ノイズと手で置いた形に」 |

## 数値の目安（2026-10-06 の結果から）

| 指標 | よく合っている | 構図・色調は合っている | まだ別物 |
|---|---|---|---|
| ΔE（OKLab ×100） | 2〜3 | 4〜5.5 | 7 以上 |
| 構図 F（輪郭の一致 ×100） | 70 以上 | 60〜70 | 55 未満 |
| 1 フレーム（1456×816） | 〜5 ms | 〜8 ms | 8 ms 超 |

模様の多い絵（草原・タイル・水）は構図 F が低めに出る（駅で 67〜77、プールは 35〜52 で構図が合っていなかった）。
