# v2 のゲームとしての面白さ（設計）

2026-10-02、段階 3 の確認で「仕掛けがただ部屋にあるだけで、ゲームとして何が面白いのかが検討できていない」とご指摘を受けて書いた。
仕掛け・部屋・隠しの作り方は、この資料の原則に従う。数値はすべて調整表（`core/config/tuning.ts`）。

---

## 1. 何が面白いのか

このゲームの面白さは、次の 3 つの感情の繰り返しにある。

| 感情 | 起こる場面 | 作り方 |
|---|---|---|
| **期待（ワクワク・ドキドキ）** | 閉じた扉の前。廊下の先の曲がり角 | 部屋は基本的に扉の向こう。扉を開けるまで中は見えない。扉の向こうの「当たり外れ」の幅を大きくする |
| **驚き（おかしさ・不気味さ）** | 扉を開けた瞬間 | 部屋の一部ではなく**部屋まるごと**がおかしい（2 章）。開けた瞬間に「何かおかしい」と分かる |
| **挑戦と発見** | 部屋を抜けるとき。普通でない振る舞いをしたとき | 部屋まるごとが 1 つの遊びになった仕掛け（3 章）。失敗には代償がある（戻される）が、閉じ込めない。普通と違うことをすると隠しが見つかる |

「閉じ込めない」「体力を減らさない」（体力の規則は後回し）の中で緊張を作るのは、**失敗すると時間と位置を失う**こと（落ちて入口からやり直す・流されて戻される・捕まって戻される）。

## 2. 扉の向こう（期待と驚き）

- **部屋はすべて扉の向こう**（入口・出口の部屋と、大きな広間の一部を除く。調整表 `floor.roomDoorChance`）。廊下は息をつく場所、扉は句読点。
- 扉の向こうの「くじ」（本道の部屋。脇道は仕掛け・隠しが少し多め）:

| 中身 | 目安 | 感情 |
|---|---|---|
| 普通の部屋（家具だけ） | 約 35% | 落ち着き。次の扉への期待をためる |
| **部屋まるごとの異変** | 約 30% | 驚き・おかしさ・不気味さ |
| **部屋まるごとの仕掛け** | 約 30% | 緊張・挑戦 |
| その他（隠し・珍しい部屋） | 少し | ご褒美 |

- **緩急**: 強い仕掛け（強さ 2 以上）は続けない。強い部屋の次は普通の部屋か異変の部屋。同じ仕掛け・同じ異変はフロアの中で続けない（`gimmick.repeatMul`・`anomaly.repeatMul`）。
- 隠し扉の先も扉（開けるまで見えない）。通路の先には扉（レア部屋・通り抜け）。

## 3. 部屋まるごとの異変（驚き。挑戦は少ない）

部屋の形・家具・光・水・重さのどれかが、部屋全体で普通でない。条件:
1. 扉を開けた瞬間に分かる（遠目で見えるおかしさ）
2. 中を歩ける・触れられる（水で遅くなる・物を押せる・暗いので懐中電灯が要る）
3. 部屋のテーマ（教室・事務所・浴場…）と重なって、「浸水した教室」「巨大な事務机」のような組み合わせになる

| 異変 | 内容 |
|---|---|
| 浸水 | 壁から壁まで膝の深さの水。家具が水に立つ。歩くと遅い |
| 巨大な家具 | 家具が 2.5〜3 倍。机の下をくぐれる。自分が小さくなった感覚 |
| 小さな家具 | 家具が 0.3 倍（人形の家） |
| 増殖 | 同じ椅子が部屋いっぱいに整列し、全部こちらを向く |
| 逆さま | 家具が天井に付いている。照明は床 |
| 積み上げ | 部屋の家具が全部、真ん中に塔のように積まれている |
| 暗闇 | 照明が全部消え、遠くに小さな灯りが 1 つ。懐中電灯が要る |
| 霧 | 3 m 先が見えない |
| 扉だらけ | 壁が扉で埋まっている（開かない扉）。1 つだけ本物の隠し扉 |
| 軽い部屋 | 重さが軽い（高く跳べる・ゆっくり落ちる） |
| 物の海 | 膝まで転がる物で埋まっている（押し分けて進む） |
| 色の異変 | 真っ赤な照明・色が抜けた部屋 |
| 散乱 | 家具が倒れ、散らばっている |

## 4. 部屋まるごとの仕掛け（緊張と挑戦）

原則:
- **部屋の形そのものを仕掛けに合わせて作る**（部屋の中に装置を置くのではない）
- **目標がはっきり**（向こうの扉へ行く）・**規則が見て分かる**（光が導く・帯が流れる・床が揺れる・梁が細い）
- **失敗に代償**（入口へ戻される・最初からやり直し）。ただし閉じ込めない（必ず戻れる道がある）
- **普通でない振る舞いに隠し**（光から離れる・わざと落ちる・流れに逆らう …）

| 仕掛け | 部屋の形 | 面白さ | 失敗 | 隠し |
|---|---|---|---|---|
| 導く光の迷路 | 真っ暗な迷路（背の高い仕切り）。光が正しい道を先導する | 光についていく安心と、離れたら迷う不安 | 迷う（時間を失う） | 光から離れて行き止まりに入ると扉 |
| 一方通行の歩道迷路 | 部屋いっぱいに、柵で仕切った動く歩道の帯。歩くより速く、逆には進めない。分かれ目で帯を選ぶ | 流れを読んで道を選ぶ。間違えると入口へ流し戻される | 入口へ戻される | ある帯の行き止まりの先に扉 |
| 崩れる床 | 部屋の床全部が深い穴の上の床板。乗ると揺れて落ちる。止まらずに渡る | 足を止められない緊張 | 深い穴の底へ落ちる。壁の階段を登って入口からやり直し | 穴の底の壁に扉（落ちた人だけが見つける） |
| 細い梁の網 | 細長い部屋の全体が深い溝。細い梁が網のように架かり、行き止まりもある | 道を選んで細い梁を渡る | 溝の底へ落ちる。階段で入口へ戻ってやり直し | 溝の底に扉 |
| 傾く床 | 部屋の床が 1 枚の板。立った方へ傾く | 物が滑る・転がる | — | 物をどかすと扉 |
| 視線のマネキン | 物の多い部屋 | 見ている間は止まる緊張 | 捕まると入口へ | — |
| 謎のパズル | 行き止まりの部屋 | 手がかりを読む | — | 正しい順で扉 |

仕掛けの id: 導く光の迷路 = `guideLight`・一方通行の歩道迷路 = `beltMaze`（廊下の動く歩道 `walkway` は削除）・崩れる床 = `crumbleFloor`・
細い道 = `narrowPath`・細い梁の網 = `beamNetwork`・傾く床 = `tiltRoom`・視線のマネキン = `mannequin`・謎のパズル = `puzzleRoom`。
異変の id は `core/gen/anomaly/defs/*.ts`（flood・giant・tiny・multiply・upsideDown・stack・dark・fog・tint・doors・lowGravity・ballSea・scatter・clocks）。

## 5. 実装の方針

- 異変は `core/gen/anomaly/`（区画の中身を置く前 `pre` と後 `post` の 2 段。置いたあと開口どうしの到達を確かめ、だめなら取り消す）
- 仕掛けは `core/gen/gimmicks/`（部屋の形を作る。到達の確認は今までどおり）
- 部屋の扉: `core/gen/floor/geometry.ts`（`floor.roomDoorChance`）
- 見本のフロア（`?showcase=1`）に異変も並べ、G キーで見て回れるようにする
