# タブレット（2026-10-06）

一人称のプレイヤーが、板の端末（10.9 型ほど・ブランドの印なし）を手に持って見る。背景と視点はそのままで、世界の中で本当に持っているように見せる。
決定は [`v2-plan.md`](v2-plan.md) の V2-16。

## 1. 仕様（利用者と決めたこと）

| 項目 | 決めたこと |
|---|---|
| 出す・しまう | Tab（`client/input/keymap.ts` の `tablet`。割り当ては 1 か所にまとめ、将来変えられる）。スマホは右の「端末」ボタン。どのアプリの状態からでもしまえ、次に出すとしまったときのアプリのまま |
| 持っている間の体 | 歩ける。ダッシュ・ジャンプ・調べる（E）・置く（Q）はできない（両手がふさがる）。物を持っている・乗り物・はしご・よじ登りの間は出せない（「手がふさがっています」） |
| ホーム画面 | カメラ・探索・マップ・SNS・ギャラリー・設定。各アプリに「戻る」（右クリック・Backspace でも） |
| カメラ | タブレットを顔の前まで上げる。画面が視界の狭い向きの 9 割ほどを覆い、残りに黒い縁（ベゼル）が見える（本体は視界を覆ったまま。調整表 `tablet.raise.screenCover`。画面の透けた所から世界が見える = カメラの映像。写真は縁の外も含めた視界の全部）。シャッターで今の画面を写真に（タブレットは写らない）。ホイール・ボタンでズーム（1〜4 倍） |
| 写真の見た目 | 既定はタブレットのカメラらしい写真（ビデオのにじみ・走査線・レンズの癖なし。露出の追従は残す）。設定の「写真の見た目」でビデオ調（画面と同じ）にもできる |
| 撮影日時 | 現実の日時 |
| 撮った所 | 写真に、撮った瞬間のカメラの位置・向き（水平・上下・傾き）・縦の画角（ズーム込み）と、プレイヤーの足元・向き・しゃがみ・階・場所の印（区画の形から作る。`spotSignature`）を残す。SNS に投稿すると投稿にも写す |
| 探索 | 9 桁のデジタルのダイアル（ホイール・ドラッグ・▲▼・数字キー・Backspace）と「移動」。初めは今いる部屋の番号。部屋があればワープ（ビデオの電源が落ちる → LOADING → 電源が入る → 部屋の開口の内側）。無い番号はタブレットの画面に「通信エラー」を出して、その場に残る |
| マップ | 今の地図（メニューの地図と同じ絵）をタブレットの画面に描く。ホイール・＋－で拡大、ドラッグで移動、「現在地」で戻す |
| 設定 | 今のメニューの設定を開く（ゲームは一時停止） |
| ギャラリー | 撮った写真の一覧（新しい順・部屋の番号・撮影日時）。押すと大きく見る。「削除」（2 回押す）・「探索」（撮った所へすぐ移る。番号の入力は通さない）・「投稿」（SNS へ。同じ写真は 1 回だけ。投稿した写真は「投稿済み」） |
| SNS | タイムライン（新しく投稿した順。投稿者名・投稿日時・ルーム ID・画像）。ホイール・ドラッグで流す。押すと大きく見て、下に「探索」（撮った所へ移る。下の「写真から移る」）・「キャンセル」・「削除」（2 回押す）。番号の無い写真・別の seed の写真・場所の記録の無い写真は「探索」できず、理由を出す。今は自分の投稿だけ（投稿者は名前と端末ごとの id を持つので、いろいろな人の投稿も同じ形で並べられる） |
| 写真から移る（2026-10-06） | ギャラリー・SNS の「探索」: 覗き込む音 → タブレットをカメラと同じ顔の前へ上げる（0.55 s。縁が見える）。画面はギャラリー・SNS の表示のまま（写真だけの全画面にはしない。近づけるので写真が大きく見える。視界いっぱいでなくてよい: 2026-10-06 ユーザーの指示）。押した瞬間から移る先を読み込み、その間は状態の行に「接続中…」・ボタンは押せない・環境音を絞る（0.8 s）。読み込みが早くても 0.8 s は顔の前のまま → 着いたら世界を写真の視点（位置・向き・画角）に重ね、タブレットをゆっくり手元へ（1.6 s。画面は元の表示のまま）。下ろし始めの 4 割は写真の視点のまま、残りで普通の視点・画角へ戻し、環境音を戻す（1.8 s）。下ろし終えるまで視点と移動は止める。移れたら、手元へ戻して 0.25 s 後に Tab と同じようにしまう（行けなかったときは出したまま: 通信エラーを読める）。数値は調整表 `tablet.travel.*` |
| 写真から移る: 決めたこと | 着いた直後は写真と同じ画角（ズーム・画面の縦横比の違いも合わせる: `revealFov`）にしてから普通の画角へ / 撮った所に今は立てなくても、そのまま置く（落ちる・押し出されることがある）/ 場所の記録の無い写真（この変更より前）・世界の作りが変わった写真（場所の印が合わない）は「この写真の場所はもう見つかりません」で押せない（写真を開いたときに確かめる）/ 移る途中で行けなかったら、下ろしたあとに画面に通信エラー / 探索アプリ（番号）の移動は今までの電源の演出 |
| 投稿の中身 | 投稿は写真の写しを持つ（ギャラリーで写真を消しても投稿は残る）。投稿者名は設定の名前（無ければ「あなた」）、投稿日時は投稿した現実の日時 |

## 2. 作り

| 所 | 中身 |
|---|---|
| `client/tablet/TabletModel.ts` | 形（three.js）。寸法は実物どおり（本体 24.86 × 17.95 × 0.70 cm・画面 22.64 × 15.75 cm）。カメラのときは本体の裏を隠す（setViewfinder）。指のカーソルは画面の絵とは別の板 |
| `client/tablet/ui/TabletUi.ts`・`paint.ts` | 画面の絵（2D canvas 1152 × 800）。アイコン・壁紙・各アプリ。描き直しは変わったときと動きのある間だけ。押せる所は描くたびに作り直し、指で当てる |
| `client/tablet/TabletController.ts` | 出す・しまう動き（0.42 s / 0.32 s。持ち上げる弧・呼吸・歩く揺れ・振り向きの遅れ）、照明（今いる所の焼き込みの光 × 露出の追従）、操作（下の表）、写真、ワープの頼み |
| `client/render/ViewmodelPass.ts` | 手に持つ物を、LensPass の後・OutputPass の前で世界の絵に重ねる（深度付きの別の絵 → 前掛けで重ねる。壁に埋まらない。ビデオのにじみ・走査線は世界と同じく掛かる。レンズの軟焦点・歪みは掛けない = 文字がぼけない）。持っていない間は描かない |
| `client/tablet/ImageStore.ts` | 写真の入れ物（IndexedDB。情報と小さい写真 / 元の写真を分ける。使えなければ開いている間だけ）。写真と投稿が使う |
| `client/tablet/PhotoStore.ts` | 写真の保存（IndexedDB `liminal2.photos`） |
| `client/tablet/PostStore.ts` | SNS の投稿の保存（IndexedDB `liminal2.sns`。投稿者・投稿日時・元の写真の id・ルーム ID・写真の写し）と、この端末の遊ぶ人の id（`liminal2.playerId`） |
| `client/settings/playerName.ts` | 遊ぶ人の名前（`?name=` → 設定の名前 → 「あなた」）。投稿者名と、異変の名前の文字が使う |
| `client/tablet/logic.ts` | アプリの並び・ダイアル（電卓のように右から入る）・日時の表示・写真の場所（PhotoSpot）・写真を覆って見せたときの画角（revealFov）と置き方（coverRect）（Node の試験 `tests/tablet-logic.test.ts`） |
| 写真から移る | `TabletController`（startTrip・stepTrip: 上げる・顔の前のまま待つ・下ろす。覗き込む音）・`TabletUi`（startTravel・travelDone: 接続中… と通信エラー）・`main.ts`（spotAt・checkSpot・travel）・`WorldSession.prepareGotoPose`（足元・向き・しゃがみのまま置く）・`ClientGame.arrive`（階を入れ替えたとき視点を合わせる・holdCrouch）・`CameraRig.hold`（写真の視点に重ね、k で普通へ戻す）・`AudioEngine.fadeAmbient`・`spotSignature`（core/gen/world/roomId.ts） |
| `client/ui/PowerFx.ts` | 電源が落ちる・入る演出（ゲームの canvas を横 1 本の線に潰して点で消す・LOADING・線から開く。音は WebAudio の合成） |
| `core/stream/session.ts` | `prepareGotoRoom`（番号の部屋の階・区域を作って開口の内側に立たせる）→ `commitGoto`。捨てる階は置いた物を書き残す（`StoryWorld.flush`） |
| `client/game/ClientGame.ts` | `HeldDevice`（毎フレームの入力と描く前の更新）・`capture`（写真の 1 枚）・`lightAt`（点の明るさ）。`CameraRig.zoom` |
| `client/map/MapController.ts` | `drawTo`（好きな 2D の画面に地図を描く） |

### 操作

| | PC（Pointer Lock 中） | スマホ（と Pointer Lock を使わないマウス） |
|---|---|---|
| ホーム・アプリ | マウスで指のカーソル（視点は止まる）・クリック・ホイール・右クリック / Backspace で戻る・数字キー・Enter | 画面を直接タップ・ドラッグ（画面の外をなぞると視点）。マウスなら右クリックでも戻る |
| カメラ | マウスで狙う・クリックでシャッター・ホイールでズーム・右クリックで戻る | なぞって狙う・シャッター / ズーム / 前の写真 / 戻るをタップ |

- カメラのとき、画面のうち見えている所（スマホの縦持ちでは真ん中の帯だけ）に合わせて部品を並べ直す（縦長はシャッターを下の真ん中）
- 細い画面（スマホの縦持ち）では、本体の幅が視界の 9 割に収まるまで離して持つ。持っている間はジャンプ・ダッシュ・置くのボタンを隠す

## 3. 試験・確かめたこと

- 試験: `tests/tablet-logic.test.ts`（ダイアル・日時・キーの割り当て・写真の保存・SNS の投稿: 新しい順・投稿済みの写真・写真を消しても投稿は残る・投稿の削除・写真から移って着いたときの画角）・`tests/world-roomid.test.ts`（場所の印・撮った所にそのまま置く）・`tests/world-roomid.test.ts`（番号の部屋へ移る: 別の階・同じ階、床に立つ、捨てる階を書き残す）・`tests/settings-store.test.ts`（photoLook）
- ブラウザ: 出す・しまう（カメラからしまって出すとカメラのまま）・ホームのアイコン・カメラ（視界いっぱい・UI が見えている所に収まる）・シャッター（タブレットのカメラの写真 / ビデオ調）・ギャラリー（一覧・大きく見る・削除）・探索（ダイアル・数字キー・無い番号の通信エラー・ワープの演出と着く部屋・アドレスの番号）・マップ・設定・物を持っているときは出せない・スマホ（端末ボタン・タップ・縦長のカメラ）
- ブラウザ（SNS）: ギャラリーの「投稿」→「投稿済み」・タイムライン（投稿者名・日時・ROOM・画像・新しい順・ホイール / ドラッグで流す・別の人の投稿の色）・大きく見る・キャンセル・探索（別の部屋から撮った部屋へワープし、アドレスとタブの名前も変わる）・探索できない理由（番号なし・別の seed）・削除（2 回）・ギャラリーの写真を消しても投稿の画像は残る・読み込み直しても残る・右クリックで戻る・スマホ（タップ・ドラッグ）
- 探索で別の区域・別の階へ移ったあとも、移った先が描かれる（2026-10-06 に直した: 移った先の描画を入れ替える前に捨てていて、前の階の描画が残り真っ暗になっていた。同じ区域の中の部屋へ移ったときは前の描画が同じ形なので気づきにくかった）。階段室の向こうに用意した階と同じ階の部屋へも移れる
- 見えない所に置いたブラウザの枠（描くのが毎秒 3 回ほどに落ちる）では、ワープが着く先の描画を作り終えられず「移動できませんでした」になる（普通に見えているタブでは 2〜3 秒で着く）
- ブラウザ（写真から移る。2026-10-06）: ズーム 1.6 倍で撮った写真をギャラリーから「探索」→ 顔の前で写真が視界いっぱい → 着いた瞬間のカメラの位置・向き・画角が写真と同じ（数値で一致・タブレットを隠した世界の絵が写真と同じ）→ 下ろしながら普通の画角へ・手元で元の画面へ溶ける・操作が戻る。SNS の投稿から同じ所へ・場所の印の違う写真と場所の記録の無い写真は押せない・移る途中で行けないと通信エラー・探索アプリの番号の移動は今までどおり
- ブラウザ（2026-10-06 の直し）: カメラ・写真から移るとき、顔の前で黒い縁が見える（縦長の画面では上下、横長では左右。前は本体の真ん中から画面の面までの厚みの分だけ近すぎて、縁が消えていた）・移れたら手元へ戻したあとしまう・行けなかったときは出したまま
- ブラウザ（2026-10-06 の直し 2）: 写真から移る間、画面はギャラリー・SNS の表示のまま近づき（写真が大きく見える・全画面の写真にはならない）、「接続中…」でボタンは押せない → 下ろす間も元の表示のまま
