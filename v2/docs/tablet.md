# タブレット（2026-10-06）

一人称のプレイヤーが、板の端末（10.9 型ほど・ブランドの印なし）を手に持って見る。背景と視点はそのままで、世界の中で本当に持っているように見せる。
決定は [`v2-plan.md`](v2-plan.md) の V2-16。

## 1. 仕様（利用者と決めたこと）

| 項目 | 決めたこと |
|---|---|
| 出す・しまう | Tab（`client/input/keymap.ts` の `tablet`。割り当ては 1 か所にまとめ、将来変えられる）。スマホは右の「端末」ボタン。どのアプリの状態からでもしまえ、次に出すとしまったときのアプリのまま |
| 持っている間の体 | 歩ける。ダッシュ・ジャンプ・調べる（E）・置く（Q）はできない（両手がふさがる）。物を持っている・乗り物・はしご・よじ登りの間は出せない（「手がふさがっています」） |
| ホーム画面 | カメラ・探索・マップ・SNS・ギャラリー・設定。各アプリに「戻る」（右クリック・Backspace でも） |
| カメラ | タブレットを顔の前まで上げ、画面が視界いっぱい（画面の透けた所から世界が見える = カメラの映像）。シャッターで今の画面を写真に（タブレットは写らない）。ホイール・ボタンでズーム（1〜4 倍） |
| 写真の見た目 | 既定はタブレットのカメラらしい写真（ビデオのにじみ・走査線・レンズの癖なし。露出の追従は残す）。設定の「写真の見た目」でビデオ調（画面と同じ）にもできる |
| 撮影日時 | 現実の日時 |
| 探索 | 9 桁のデジタルのダイアル（ホイール・ドラッグ・▲▼・数字キー・Backspace）と「移動」。初めは今いる部屋の番号。部屋があればワープ（ビデオの電源が落ちる → LOADING → 電源が入る → 部屋の開口の内側）。無い番号はタブレットの画面に「通信エラー」を出して、その場に残る |
| マップ | 今の地図（メニューの地図と同じ絵）をタブレットの画面に描く。ホイール・＋－で拡大、ドラッグで移動、「現在地」で戻す |
| 設定 | 今のメニューの設定を開く（ゲームは一時停止） |
| ギャラリー | 撮った写真の一覧（新しい順・部屋の番号・撮影日時）。押すと大きく見る。「削除」（2 回押す）・「この部屋へ」（探索に番号を入れる。同じ seed の写真だけ） |
| SNS | アイコンだけ（押すと「準備中」） |

## 2. 作り

| 所 | 中身 |
|---|---|
| `client/tablet/TabletModel.ts` | 形（three.js）。寸法は実物どおり（本体 24.86 × 17.95 × 0.70 cm・画面 22.64 × 15.75 cm）。カメラのときは本体の裏を隠す（setViewfinder）。指のカーソルは画面の絵とは別の板 |
| `client/tablet/ui/TabletUi.ts`・`paint.ts` | 画面の絵（2D canvas 1152 × 800）。アイコン・壁紙・各アプリ。描き直しは変わったときと動きのある間だけ。押せる所は描くたびに作り直し、指で当てる |
| `client/tablet/TabletController.ts` | 出す・しまう動き（0.42 s / 0.32 s。持ち上げる弧・呼吸・歩く揺れ・振り向きの遅れ）、照明（今いる所の焼き込みの光 × 露出の追従）、操作（下の表）、写真、ワープの頼み |
| `client/render/ViewmodelPass.ts` | 手に持つ物を、LensPass の後・OutputPass の前で世界の絵に重ねる（深度付きの別の絵 → 前掛けで重ねる。壁に埋まらない。ビデオのにじみ・走査線は世界と同じく掛かる。レンズの軟焦点・歪みは掛けない = 文字がぼけない）。持っていない間は描かない |
| `client/tablet/PhotoStore.ts` | 写真の保存（IndexedDB `liminal2.photos`。情報と小さい写真 / 元の写真を分ける。使えなければ開いている間だけ） |
| `client/tablet/logic.ts` | アプリの並び・ダイアル（電卓のように右から入る）・日時の表示（Node の試験 `tests/tablet-logic.test.ts`） |
| `client/ui/PowerFx.ts` | 電源が落ちる・入る演出（ゲームの canvas を横 1 本の線に潰して点で消す・LOADING・線から開く。音は WebAudio の合成） |
| `core/stream/session.ts` | `prepareGotoRoom`（番号の部屋の階・区域を作って開口の内側に立たせる）→ `commitGoto`。捨てる階は置いた物を書き残す（`StoryWorld.flush`） |
| `client/game/ClientGame.ts` | `HeldDevice`（毎フレームの入力と描く前の更新）・`capture`（写真の 1 枚）・`lightAt`（点の明るさ）。`CameraRig.zoom` |
| `client/map/MapController.ts` | `drawTo`（好きな 2D の画面に地図を描く） |

### 操作

| | PC（Pointer Lock 中） | スマホ（と Pointer Lock を使わないマウス） |
|---|---|---|
| ホーム・アプリ | マウスで指のカーソル（視点は止まる）・クリック・ホイール・右クリック / Backspace で戻る・数字キー・Enter | 画面を直接タップ・ドラッグ（画面の外をなぞると視点） |
| カメラ | マウスで狙う・クリックでシャッター・ホイールでズーム・右クリックで戻る | なぞって狙う・シャッター / ズーム / 前の写真 / 戻るをタップ |

- カメラのとき、画面のうち見えている所（スマホの縦持ちでは真ん中の帯だけ）に合わせて部品を並べ直す（縦長はシャッターを下の真ん中）
- 細い画面（スマホの縦持ち）では、本体の幅が視界の 9 割に収まるまで離して持つ。持っている間はジャンプ・ダッシュ・置くのボタンを隠す
