# 作り込む小物（client/props）

植物・棚の本や商品・寝具・便器・洗面器・流し台・自販機の中・時計・掲示の紙・持てる物などを、箱の組み合わせではなく
**形の関数**（部位ごとの曲面 + 模様の関数）で作ったメッシュで描く。作り方の手順は `.claude/skills/procedural-3d-objects`、
どの物を作り込むかの振り分けは `experiments/v2-splat-props/CLASSIFICATION.md`（箱とテクスチャで作れる机・棚の枠・ソファなどは箱のまま）。

**シミュレーションは変えない。** 当たり判定・仕掛け・異変は今までの箱のまま動き、描画だけを差し替える。

## 流れ

1. **見つける**（`plan.ts` の `planCell`）: 区画の箱の propGroup（`plant@…`・`shelf@…`・`booths@…` など）と、箱の大きさ・材質・並び・向きから、
   作り込む小物と、その作り方（`PropSpec`: 種類・置き場所・向き・大きさ・引数・乱数の種。データだけなので Worker へ送れる）・
   隠す箱・差し替え中だけ出す箱（流しの下を抜いた台）を決める。propGroup の無い壁の小物（時計・灯り・消火器・掲示の紙）と
   部屋に直に置かれる物（布団・座布団・カーテン・リング・ボールプール）は材質と寸法で見つける
2. **区切る**（`PropManager.plan`）: 小物を 8 m の区切り（タイル）に分ける。`FloorBuilder` は差し替える箱を区切りごとの別のメッシュ
   （`CellProps.placeholders`）にし、差し替え中だけ出す箱も別に作って隠しておく（`CellProps.adds`）
3. **作る**（`PropManager.update`。毎フレーム）: カメラに近い区切りから 1 つずつ、Worker（`props.worker.ts`）で形の関数 → 曲面 →
   アトラスと頂点の配列（`atlas.ts`）を作り、メインで頂点に焼き込み光を付けて v2 の材質のメッシュにする（`propMeshes.ts`）。
   テクスチャは先行アップロードの待ち行列で少しずつ GPU へ載せ、シェーダを用意してから、元の箱と入れ替える
4. **距離で細かさを変える**: 近い区切り（high で 10 m）は細かく、もう少し遠い区切り（22 m まで）は棚の中身を粗く作り、
   far（32 m）より遠い状態が 1.5 秒続いたら捨てて箱に戻す（霧の中なので、遠くの小物はほとんど見えない）。距離・細かさ・模様の細かさは
   画質ごと（`PROP_LOD`）。スマホはどの画質でも low の値
5. **持てる物**（`views/carry/items.ts`）: kind・大きさ・色ごとに 1 回作り（`PropManager.carryTemplate`）、形とテクスチャを共有した写しを置く。
   作り終わるまでと、形の関数が無い kind は箱の組み合わせ。持つ・置く・投げる・水を汲む・運ぶと変わる・音は今までどおり

## 見た目を揃える決まり

- **照明**: 小物は区画の焼き込み照明（器具の配光・遮蔽・接触の陰）で焼く。差し替える箱は遮蔽物から除く（箱の中の物が箱の陰で
  暗くならないように）。部品で入切する照明（lamp）の区画は「その照明なし」も焼いて `built.blend` に足す（照明を消すと暗くなる）
- **材質**: `MaterialLibrary.adoptExternal`（焼き込み光・霧・色が抜ける異変の注入）。区画の render の霧と色のマスクを渡す。
  模様なし・旧版風（render.style）の区画は箱のまま
- **異変**（`core/gen/anomaly` の `markChanged`）: 異変が変えた（位置・大きさ・材質・当たり判定・種類）・足した箱に `Box.odd` を付ける。
  その箱を含む物・その箱に触れる物（上に積もった埃・雪、置いたマグ、引きずった跡）・異変の鏡の写し（`~m`）の元の物は差し替えない。
  傾けた・裏返した・大きさや色を変えた物は箱のまま（異変の見た目がそのまま残る）。異変の物（`/a-`）・持ち込んだ物（`/c-`・`/x-`）も箱のまま
- **写した物**: 乱数の種は propGroup から区画・区域の名前と写しの印（`:m`・`:k1`・`~m`・`L2-`）を除いた所（`normalGroup`）、
  propGroup の無い物は寸法と床からの高さ（位置は使わない）。warp の双子（Box.uvFrame・区画の uvFrame）は元の位置へ戻してから見つけ、
  作り方を同じ写し方で写す。階段室（frame 'group'）は局所の座標の写しで見つける。どれも元の部屋と同じ見た目になる
- **時計の時刻**は v2 の針の箱から（長針は真上、短針が見る人の右なら 3 時・左なら 9 時）

## 箱のままの物（まだ作り込まない）

- 部品の描画が箱を組み直す物: 集める本の棚（collectSet）・写しの並ぶ所（replicaField）・崩れる山（propPile）・回る椅子（senseFx chairs）・
  異変の回る物（oddRoom fx spin / grow）・warp の写しの描画（swapSet・lap・recede・turn）・mirrorRoom の床の映り込み
- 箱とテクスチャで作れる物（机・椅子・棚の枠・ソファ・ロッカー・カウンターなど。振り分けどおり）

## 開発用

- `?props=0` で箱のまま。見本・`?dev=1` では P で 形の関数 ↔ 箱 を切り替える
- `game.props.stats()`: 区切り・作った区切り（うち細かい）・小物・三角形・GPU の量・種類ごとの数・作れなかった数
- 試験: `tests/props.test.ts`（形の関数がどれも作れて同じ種で同じ形・予算・計画の決まり・双子・異変・FloorBuilder と照明の入切）
- 新しい小物を足すとき: `gen/*.ts` に形の関数（見本の部屋 `experiments/v2-splat-props` で撮って直す）→ `registry.ts` の `GEN` に種類 →
  `plan.ts` で区画の箱から見つける → `tests/props.test.ts` の `SAMPLES` に見本
