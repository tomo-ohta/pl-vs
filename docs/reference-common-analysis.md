# 参考画像「COMMON 現実に近い基礎ステージ例」の分析と配置方針（2026-09-16）

ユーザー提供の参考ボード（Common 20 ステージの写真風イメージ）を読み取り、ゲームの各テンプレートで「何を・どこに・どれだけ」置けば近い見た目になるかを整理する。
共通の結論: **写実性は小物の量ではなく、建築の反復リズム・照明の一貫性・床の反射・壁の二段構成・短いサイン文字で決まる。** 小物はテンプレートの意味を示す大きなもの（椅子列・ロッカー・棚・洗濯機・カート）だけを、壁に沿って規則的に置く。

## 全ステージに共通する視覚文法

1. **強い一点透視と反復**: 扉・照明・タイル目地・柱が等間隔で奥へ続く。廊下は長め（24〜40 m）で、突き当たりは暗く沈む。
2. **照明は器具の列**: 天井の蛍光灯（トロファーまたは露出管）が中心線に 1 列、または 2 列。器具の直下だけ明るく、壁上部に光の滲み。器具の間は暗い。全体は少し暗め（露出 −0.5 段相当）。
3. **床の反射**: リノリウム・タイル・駐車場コンクリートは低い粗さで天井灯が床に映る。カーペットは均一で模様が主張しない。
4. **壁は二段**: 下 1.0〜1.2 m が腰壁（別色・別素材）または巾木 + 手すり。上は無地。天井との境に廻り縁。
5. **サインは短い文字**: 部屋番号（101）、階（B1、3）、案内（← 1-4 5-8 →）、注意書き（従業員専用 / STAFF ONLY）、標語（食でつながる、今日もいい一日を）。壁の中央付近に 1〜2 枚。
6. **彩度は低く、差し色 1 つ**: 黄色（駐車場の帯・倉庫の床線・濡れ床）、緑（ロッカー・非常口）、赤茶（カラオケ・ホテル）。
7. **物は壁沿いに列で**: 中央は空ける。列の向きは廊下軸に揃える。

## ゲームへの落とし込み（優先順）

1. **壁の二段構成と巾木・廻り縁・手すり**を全テンプレートの外殻に（Generator 共通処理）。テンプレートごとに腰壁の高さ・素材・色を指定。
2. **照明の列**: 器具は中心線に等間隔。トロファーはグリッド天井に埋め込み、露出管は天井から 10 cm 下がったペア。器具の間隔 3.0〜3.6 m。焼き込みでは器具直下が明るく壁上部に滲む。
3. **床の反射**: リノリウム・タイル・駐車場は roughness 0.25〜0.35。カーペットは均一（Carpet004 は不採用。Fabric028 を暗い暖灰色に）。
4. **扉のリズム**: 廊下の扉は 2.8〜3.2 m 間隔で両側に並べ、番号プレートを付ける（実際に開くのは接続のある扉だけ。他は施錠の装飾扉）。
5. **テンプレート固有の大物**（コード生成の箱を「本物の比率」で組む）: 連結椅子、ロッカー列、スチール棚 + 箱、洗濯機列、トイレブース、カゴ車、自販機、長机 + 椅子。細かい小物は置かない。
6. **サイン**: SignAtlas で短い日本語 / 英語の標語・番号・案内を壁中央 1.6〜1.9 m に。
