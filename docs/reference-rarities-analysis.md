# 参考画像（Uncommon / Rare / Epic / Legendary / Mythic ボード）の分析と配置方針（2026-09-17）

ユーザー提供の 5 枚のボード（各 20 ステージ）を読み取り、定義 ID ごとに「ぱっと見の印象を決める要素」を整理する。全て再現する必要はないが、**第一印象がボードと同じ方向を向くこと**を目標にする。Common の分析（docs/reference-common-analysis.md）の視覚文法（反復リズム・器具の列・床の反射・壁の二段構成・短いサイン・差し色 1 つ・大物は列で）は共通の前提。

実装は `src/generators/dressing/<rarity>.ts`（定義 ID で分岐する決定論の後処理）で行い、既存の Generator / Modifier / 材質は変えない。予算: 部屋あたり 箱 +300、三角形 +40k、ライト +2 以内。反復物は `L.instances`。文字は `L.signs`（SignAtlas: plate / emissive、部屋あたり最大 3 枚のアトラス = 48 サイン）。

凡例: 【床 / 壁 / 天井】【光】【大物】【サイン】【差し色】。「保留候補」= 画像だけでは雰囲気が伝わりにくい、または現行の仕組みでは印象を出せないもの。

## 軽量化の規則（部屋切り替え時のフリーズ防止）

- ドレッシングは箱数 +300 以内、三角形 +40k 以内、追加ライト 2 灯以内。同型の反復（椰子、椅子、ボトル、書架）は `L.instances`。
- 新しい材質族は増やさない（既存の MatId と、今回追加した marbleFloor / woodPanel / bookshelfWood / carpetPattern / redShutter / neonRed / neonBlue / goldTrim / stainless / whiteFabric / plasticRed / plasticYellow / plasticBlue / chalkboard / aquariumBlue / skyDay / seatRed / lockerBlue / screenDark を使う）。
- テクスチャの初回アップロードは隣接部屋の配置時に先読みし、1 フレームに 1〜2 枚ずつ GPU へ送る（担当 L2）。
