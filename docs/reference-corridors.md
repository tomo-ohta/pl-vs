## 共通の作り

- **乱数**: 装飾・照明はすべて `vr.fork('ref')` の専用列。幅・形状・ソケット・床穴の乱数列は変えていない（旧生成器との比較で 12 部屋 × 3 seed × 4 variant のソケット / 足跡 / 穴が全て一致、2 回生成の JSON 一致 = 決定論 OK）。
- **壁の区間**: `wallSpans` の各区間を進行方向（セグメントの heading）に対して left / right / end に分類する。+Z を向いたとき右手は −X（`(hd + 3) % 4`）。左右で役割を分ける（学校: 左 = 教室扉・掲示板、右 = 窓帯 / マンション: 左 = 玄関扉、右 = 手すり壁 + 夜景）。
- **等間隔の枡（slots）**: 壁に沿って 3.0〜4.0 m ピッチで中央寄せ。既存ソケットの開口 + 前後 1.6 m と、隅 1.2 m（ベンチは 1.8 m）を避ける。枡番号 i で役割を交代させる（例: 学校は 3 枡ごとに掲示板）。
- **装飾扉**: 枡（trim または metalDark、壁面から 5 cm）の上に 5 cm 浮かせた扉箔（0.9 × 2.05 m、厚 3 cm）+ 金属のレバー。開かない・非ソリッド。番号 / 室名は `L.signs` の plate（扉脇 1.55 m、学校は扉上 2.3 m、カラオケは扉面）。部屋あたりのサインは 44 枚まで（SignAtlas 3 枚 = 48 の余白を残す）。
- **壁の二段構成**: `common.wallBands` で腰壁を貼る。腰壁は 1.2 cm の薄板にし、RoomBuilder の `ArchitecturalDetails` が壁箱ごとに自動で付ける巾木（trim 0.11 m、1.8 cm 出）と廻り縁（0.055 m）が腰壁より前に出るようにした（巾木・廻り縁の箱を二重に持たない）。金属巾木が要る通路（従業員 / カラオケ）だけ metalDark の帯を 3.5 cm 出して自動巾木を覆う。
- **照明の列** `lightRow`: セグメント中心線に 1 列（幅 3 m 超は 2 列）、ピッチ 3.0〜3.6 m。troffer（グリッド天井の 0.6 × 1.2 埋め込み。トレイは自動）/ tubes（metalDark の器具箱 0.3 × 1.3 を天井に付け、その下 8〜10 cm に 1.2 × 0.09 の管 2 本）/ downlight（0.12 m 角。0.15 m 未満なので自動トレイが付かず 1 箱）。消灯は lightingPreset の「一部消灯 / 低照度 / 暗」で 30%、それ以外 5%。PointLight は器具 2 つに 1 つ。
- **小物は置かない**: 旧 CorridorOffice の officeProps（植木・ゴミ箱・消火器・段ボール・濡れ床看板・時計・カメラ・火災報知器）とガラス帯を削除。プロップ kind は使わない。

## 判断・未解決

- 病院の連結椅子はソリッド（コライダあり）。分析表の「主要オブジェクト」と解釈し、壁付き 0.57 m 以内・ソケットから 1.6 m 以上・隅 1.8 m 以上に限定した。装飾扉・帯・手すり・レール・サインは全て非ソリッド。
- 装飾扉は壁面から 8 cm 出る「浮き扉」。壁を掘って引き込むにはシェル（`buildShell`）側の開口処理が要る（footprint.ts は担当外）。
- 床の艶（学校 / 病院のリノリウム、従業員通路の塗床）は材質側（`floorLino` = Tiles040、`floorConcrete`）。CC0 の差し替え候補は `docs/cc0-requests.md` に追記が必要。
- 駅 / 地下歩道の天井（アーチ、蛍光灯ライン）、マンションの夜景（遠景の明かり）、ホテルの模様カーペットは今回未着手。
- lightingPreset の語からの照明推定より `CORRIDOR_LIGHT`（presets.ts）を優先するため、CorridorHotel を使う U02 / U08 / R11 / E03 / E18 なども暖色 0.7 に揃う。個別に色を変える Modifier（EraPreset など）はその後で上書きするので影響しない想定。
- 踏破テスト中に一度 `ERROR frame: socket not found r1/entry`（Game.checkHole → spawnPointOf(開始部屋)）がコンソールに出た（本作業前のテレポート操作時）。開始部屋は entry ソケットを持たないため落下復帰で例外になる既存の経路で、廊下装飾とは無関係。踏破 3 seed の `world.log` には出ていない。
