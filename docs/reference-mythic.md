# Mythic 14 部屋の部屋別ドレッシング（担当 M・2026-09-17）

`docs/reference-rarities-analysis.md` の MYTHIC 表を目標に、`src/generators/dressing/mythic.ts`（新規実装。以前はスタブ）で M01 / M02 / M03 / M04 / M07 / M08 / M11 / M12 / M13 / M14 / M16 / M17 / M18 / M19 の「ぱっと見の印象」を足した。M05 / M06 / M09 / M10 / M15 / M20 は欠番・オミット。
変更ファイルは `src/generators/dressing/mythic.ts` だけ（共有ファイルへの要望は `docs/visual-requests.md` の「M →」節）。スクリーンショットは `docs/reference-mythic/*.jpg`（seed 7、Tier high、静的ビルド `vite build` + `vite preview` で撮影）。

## 共通の作り

- `generateLayout` で Generator 直後・Modifier の layout フックより前に `dressMythic(L, p, rng)` が呼ばれる。乱数は渡された `rng`（`p.rng.fork('dress')`）を定義 ID でさらに fork したものだけ。footprint・ソケット・扉前ゾーン（`doorZones`）・既存ソリッドは `canPlace` で避ける（M18 だけ外殻を窓の擬似ソケットで組み直す）。
- 文字は `L.signs`（SignAtlas plate / emissive）。合計 44 枚を上限にして後段の Modifier（DynamicMapNode の扉上サイン、SelfMap の名札、GraphReference の額縁名札 12 枚）の分を残す。
- 反復物は `L.instances`（M01 の格子・輪郭、M02 の立方体、M07 / M19 の床矢印、M11 の扉・枠・扉灯・床線、M14 の支柱）。**焼き込み（SurfaceLighting）のコスト**: 発光箔は 1 枚ずつ面光源（器具）になり、長い箔は 1.25 m 刻みの頂点が増えるので、数の多い物は InstancedMesh にした（M11 で構築 112 → 下表の値）。
- 後段の Modifier と重ならない工夫: M01 は SelfMap の地図板のスロットを `wallSlots` を同じ引数で呼んで先読みし、その壁面を空ける（`selfMapReserve`）。M16 は GraphReference の額縁スロットを同様に先読み（タイトル壁が置けないときの壁サイン用）。M12 は ScaleAnomaly ×4 で全部拡大される前提で、人の寸法で見せたい物を 1/s で置く（`dpre()`）。M13 は RenderStyle が内装を全部捨てるので箱を足さず `lighting.occlusion = false` だけ。
- SmallRoom 系（M01 / M02 / M04 / M08 / M18）と Gallery（M16）は汎用パターンの家具島（0.45〜1.1 m の低い塊）を取り除いてから置く（`stripIslands`）。器具・帯・間仕切りは残す。

## 保留と理由（まとめ）

- **M02 のピクセル溶解**: 専用シェーダが無いので立方体の散布で近似。壁の向こうが透ける表現は無い。
- **M04 / M08 の「扉の外」**: footprint の外に箔を出すと隣接して配置される部屋（M04 は FakeExit の行き先、M08 は他の接続）の中に現れるので、壁面の絵（M04）・ランマ（M08）で近似。
- **M11 の多層扉**: 装飾扉の段で近似（本物の上階は無い）。扉灯の多くは壁を照らさない。
- **M12 の人影**: 置かない（保留）。
- **M13 の「扉 1 枚」**: 出口数は変えない。GTAO の薄い影は P への要望。
- **M18 のガラス**: transmission 越しの Points の描画が未確認のため開口のまま。
