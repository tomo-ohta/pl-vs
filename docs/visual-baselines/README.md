## 実装した改善

- 生成済みカラー画像は維持。壁紙・カーペット・天井吸音材・木材の凹凸と粗さを、色柄とは独立した周期的な微細構造へ分離。R=高さ、G=相対粗さの256角DataTextureを使用。実測PBRではない。
- C02が使うCorridorOffice系テンプレートの静的照明は、発光面4点サンプルと下向き配光で計算。描画用の細部も遮蔽に含め、遮蔽物を近傍だけに絞らず部屋内全体から検査する。
- CorridorOfficeの動的光を下向きSpotLightに変更し、天井の丸い光斑を除去。その他の系統の点光源は維持。
- ライト選択は距離のヒステリシスと固定スロットを導入。退出光が0近くへ減衰してから次の光へ割り当てる。ライト上限は移行中も維持する。
- 検証画面にseed/variant/露出/診断表示、URLによる条件復元、PNG＋JSON保存、120フレーム計測を追加。

## 保存・復元方法

`npm run dev -- --host 127.0.0.1` で起動し、`/visual-review.html?room=C02&view=entry&tier=high&seed=42&variant=0&exposure=1.25&diagnostic=beauty` を開く。描画領域は1280×720固定。URLに4種類の視点と生成条件を保存し、JSONに実際のカメラ位置・姿勢を記録する。

「120フレーム計測」の終了後、「変更前を記録」または「変更後を記録」でこのディレクトリへPNGとJSONを保存する。固定ディレクトリへ日時名で新規保存する開発専用APIで、既存ファイルは上書きしない。本番ビルドに保存APIと確認画面は含まれない。
