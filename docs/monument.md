# 謎の物体（モニュメント）

作成: 2026-09-23。「意図や用途が想像できない物体」「どう成立しているのか分からない物体」を、種類ごとの文法でシードから組み立てて置く。

## 構成
- 仕様: `src/generators/monument/types.ts`（`MonumentPart` = プリミティブ + 位置 / 回転 / 寸法 / 材質、`MonumentSpec`）。プリミティブは box / cylinder / sphere / ring / stairs / frame / ribbon / tube / plate。
- 文法: `src/generators/monument/<kind>.ts`（officeTotem 事務トーテム / stoneFrame 石の枢組み / ribbon 帯 / cubeCluster 立方体の群 / colorStack 色の積層 / steel 赤い鉄）。`buildMonument(kind, rng, options)` が入口。
- 描画: `src/render/MonumentGeometry.ts` が three.js のプリミティブで組み立て、材質ごとに結合。RoomBuilder は車両と同じ special 部品として扱う（チャンク分割・ライトマップの対象外、頂点焼き込み）。
- 当たり判定: 基壇と主要部品の外接箱を `kind: 'colliderOnly'`（描かない）の箱で L.boxes に置く。浮いた部品の下は通れる。
- 配置: `src/generators/oddity/monument.ts`（`space.monument`、主題可、重み 4）。屋内は入口正面の中央に 1 基（高さ 天井 −0.3）、屋外系（街路・中庭・広場・団地・万博）は 6〜15 m を 1〜3 基。種類は床・壁材から選ぶ。真上に見えない光源（emitOnly）。
- 刻印: 文法が返す `signs`（ローカル位置と面）を板サインとして L.signs へ。

## 各文法の仕様（2026-09-23 統合）

| kind | 構成 | 部品 / 三角形 |
|---|---|---|
| officeTotem 事務トーテム | 基壇 + 柱（直径 0.5〜0.8）。0.45〜0.6 m ごとに 1〜3 方向へ引き出し（半数は引き出されている）・椰子（28% で上下逆 / 横向き）・電話機（受話器が 0.4〜1 m 垂れ、コードは tube）・小箱を取り付け、パイプ 2〜4 本が柱に沿って上がり途中で折れる。4 割で頂部に横向きの椰子。刻印 `SIT / FILE / CALL / WAIT / REPEAT` 系 3〜5 語 | 42〜83 / ≤ 7,800 |
| steel 赤い鉄 | 脚 2〜3 本（最大 25° 傾く、ベースプレート・ボルト・ガセット）、上端を結ぶ太管 1〜2 本、切れた管 3〜6 本（3 割下向き、半数は半割の重ね）、円盤 1〜3 枚。刻印 `NO. n` | 40〜80 / ≤ 7,800 |
| stoneFrame 石の枢組み | 基壇（屋外は階段付き）、柱 2〜4 本（1 本は 3〜8° 傾く）、片側だけ持ち出した梁、口の字の枢 1〜3 枚（必ず 1 枚は足跡の外で浮く）、円環 1〜2（1 個は柱を貫き 5 割で鏡面球、1 個は浮く）、行き先の無い階段 1〜2（3 割で逆さ吊り）、細棒 1 本で吊った浮く立方体 1〜3。刻印 `A HIGHER CIRCLE` / `STILL WE RISE` 系 | 24〜25 / 1,400〜3,800 |
| cubeCluster 立方体の群 | 基壇と逆円錐の支点（unit = H × 0.2 に比例）、幹 3〜6 段 + 枝の立方体 6〜14 個（5 割が 10〜35° 回転、5 割が 0.1〜0.4 m 浮く）、貫通する枢 2〜4 枚、親子の立方体を結ぶ細棒 4〜8 本。基壇に 4 桁の年号 | 22〜29 / 760〜1,250 |
| ribbon 帯 | 帯 2〜3 本（幅 H × 0.12〜0.2、S 字 / 閉じない輪、末端は空中）、帯面に沿う穴の縁（ring）4〜8、鏡面球 3〜5（1 個は浮く）、基壇（屋外は水盤）。姿勢は描画側と同じ Frenet 枠で計算。刻印 `A SOFTER GEOMETRY` 系 | 16〜24 / ≤ 7,900 |
| colorStack 色の積層 | テラゾーの円柱基壇 + 5〜9 段（円柱 / 箱 / 水平・立てた円盤 / 球。原色は隣接非同色、22% でガラスの円盤）、ジグザグ 5〜8 個、螺旋の帯 1 本、頂部の球（35% ネオン赤） | 17〜26 / 2,100〜2,600 |

- 歪み（`distort`）は傾き・浮き・寸法のばらつき・貫通の確率に線形で掛かる。すべて高さ o.height ± 15%、足跡 radius × 1.2 以内を Node で確認（各担当のスクリプト `scratch/m1〜3.mts`、git 対象外）。

## 増幅（2026-09-23。`index.ts` の amplify）
文法の出力に共通の後処理で派手さと広がりを足す（ユーザー指示: 地味なので物理的におかしな接続でもよいから奇妙で広がりのあるものに）。度合いは 0.6 + distort × 0.8。
1. 反響: 部品 3〜7 個を複製して足跡の 0.7〜1.6 倍の外側・上方へ飛ばし、傾け、5 割は種類別のアクセント材質（ステンレス・ネオン・ガラス・原色）に差し替える。
2. 棒: 部品どうしを 4〜8 本の細い円柱で「ありえない」つなぎ方で結ぶ（2 点間の方向へ回した円柱。25% はネオン）。
3. 軌道: 頂部の周りに傾いた大きな円環 1〜2 個と、その上の球 1〜3 個。
4. 持ち出し: 上部から水平に足跡の 1.2〜2 倍まで伸びる梁と、先端の支えの無い重い立方体（または球）。
5. 破片: 外殻 0.8〜1.6 R に小さな箱・板 8〜16 個（半数はガラス・ネオン・ステンレス）。
6. ネオン管: 部品の中心 4〜6 点を縫う発光管 1 本（ブルームが乗る）。
追加は部品 +45・三角形 4,000 以下。当たり判定は足さない（浮いた部品の下は通れる）。足跡の半径は部屋の短辺の 1/2.4 まで、高さの 0.6 倍を目安に広げた。

## 統合時の修正
- `partBounds` を回転を実際に掛けた 8 隅の外接箱に（傾いた柱が最大辺の立方体に膨らんでいた）。
- 帯（ExtrudeGeometry、非インデックス）と他プリミティブ（インデックス付き）を同じ材質で結合すると `mergeGeometries` が失敗して材質グループごと消えていた → 非インデックスに揃えて結合。
- 配置の yaw 回転が描画（makeRotationY）と逆向きだった → 修正（yaw 90° / 270° で当たり判定と刻印がずれる）。
- 展示光 1.2 m 角 → 0.45 m 角（近距離の白飛び）。屋内の足跡半径は高さの 0.45 倍かつ部屋の短辺の 1/3 以内。
