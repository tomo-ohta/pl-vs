| 点 | 決定 |

作りながら決めたこと:

- タブレットを出している間は、歩く・見回すはできるが、ボタンは押せない（v2 と同じく照準を消す）。空中のホログラムは視線に少し遅れてついてくる（少し目をそらすと部屋の手がかりが見える）
- 設定（タブレットの見せ方・マウス感度・音量）とデバッグは、Esc の一時停止の画面にまとめる。デバッグの「次のヒント段階へ」は `N` キーとコンソールの `debug.nextStage()` でも
- 文字は Web フォント（Chakra Petch・Share Tech Mono・Zen Kaku Gothic New。top-page-lab と同じく Google Fonts）。読めないときは端末のフォント
- タブレットの画面は 16:10（論理 1920 × 1200）。1.92:1 では地図が縦に詰まって小さかったため、地図の枠を縦に広げた
- タブレットは、しまったときのタブのまま次に出る（v2 と同じ。最初は MAP）
- ヒントのタブを 1.2 秒見たら、その部屋の新着の印（NEW）を消す。解放の瞬間は画面の上に通知・縁の光・音

## 依頼の要点（2026-10-15）

- 主な目的は **謎解きとヒントの出し方** のテスト
- 簡易 3D の **100 部屋** がつながった地図（大きさ・つながりはある程度ランダム、高低差のない 2 次元）を **一人称** で探索する
- 部屋ごとに **踏破**（一度でも入ったか）と **制圧**（謎を解いたか）のフラグ
- 部屋の難易度は 0 / 1 / 2 / 3 = 50 / 25 / 20 / 5 %、ランダムに配置
- 謎はボタン。難易度 0 はボタン 1 個で押した瞬間に制圧。難易度が上がるとボタンが増え、決まった順に押さないと制圧にならない
- 部屋ごとにヒント 1〜3（1 は抽象的、3 は答えにかなり迫る）。制圧 50 / 75 / 95 部屋で、全部屋のヒント 1 / 2 / 3 を解放
- v2 を参考にタブレット。タブは「全体マップと進行率バー」（既定）と「今いる部屋のヒント」の 2 つだけ
- UI はホログラム基調で、おしゃれで先進的に。進行率バーは 1 本で踏破（水色）と制圧（橙）を表示、バーの上に今の %、バーの下にヒント段階の目盛り
- デバッグ: 制圧率を次のヒント段階まで上げるコマンド

### 読み取ったこと

難易度の内訳を易しい順に足すと 50 → 75 → 95 → 100 で、ヒントの境目（50 / 75 / 95）と一致する。易しい部屋から全部解いていくと、
「難易度 0 を全部 → ヒント 1 が開いて難易度 1 へ」「難易度 1 を全部 → ヒント 2 が開いて難易度 2 へ」…と、次の難易度に挑むときにちょうどヒントが 1 段上がる。
そこでヒントの文は「難易度 1 はヒント 1 だけで解ける、難易度 2 はヒント 2 まで、難易度 3 はヒント 3 まで」で効くように作る。
易しい部屋を飛ばして進む人は境目に届くのが遅れる（それ自体がテストで見たい所と考える）。

## 1. 地図（100 部屋）

- 1 m 単位の升目に、長方形の部屋を **すでにある部屋の壁に接ぎ足して** 100 個まで育てる → 外形が不揃いで、行き止まりと回り道のある地図
- 部屋の大きさ: 一辺 5〜13 m ほどのランダム。天井 3 m。高低差なし
- つながり: 壁を 2 m 以上共有する部屋どうしが候補。全部屋がつながる木 ＋ 残りから 2 割ほど足して回り道を作る。つながりごとに扉の開口（幅 1.2 m）
- 扉はいつも開いている（施錠なし。謎を解かなくても先へ進める）
- seed で決まる（既定は固定、`?seed=` で変える）。同じ seed なら同じ地図・同じ謎
- 部屋番号 001〜100（スタートが 001。近い部屋ほど近い番号）

## 2. 一人称の探索

- PC: クリックで視点を固定（Pointer Lock）、WASD / 矢印で移動、マウスで見回す、Shift で走る、照準の先のボタンを左クリック（または E）で押す
- 壁との当たり判定（円と箱）
- 見た目は簡易 3D: 単色の床・壁・天井、天井の照明パネル、部屋ごとに少し違う色味、扉の上に部屋番号の札
- 画面の HUD（最小限・ホログラム調）: 照準、今いる部屋（番号・難易度・踏破 / 制圧）、上端の方位の帯（ヒントの「北の壁」などのため）、通知

## 3. フラグ・難易度・保存

- 各部屋に `visited`（踏破: 部屋の床に一度でも入った）と `solved`（制圧）。制圧した部屋は必ず踏破済み
- 難易度はちょうど 50 / 25 / 20 / 5 部屋（数を決めて混ぜる）。スタートの部屋だけ難易度 0 に固定（操作を覚えるため）
- 進行は localStorage に seed ごとに保存。読み込み直しても続きから

## 4. 謎（ボタン）

- ボタンの数（案）: 難易度 0 = 1 個、1 = 3 個、2 = 4 個、3 = 5 個
- 押したボタンは点灯し、押した順の番号が付く。判定のしかたは「確認したいこと 2」
- 正解: ボタンが橙に変わり、部屋の照明が変わり、音と通知。不正解: 赤く点滅して全部戻る
- 部屋の中に「順番の手がかり」を置く案（「確認したいこと 1」）。型の候補:

| 難易度 | 型 | 手がかり | 正しい順 |
|---|---|---|---|
| 0 | 押すだけ | なし | — |
| 1 | 点の数 | 各ボタンの上に 1〜3 個の点 | 少ない順 |
| 1 | 台の高さ | ボタンの台の高さが違う | 低い順 |
| 1 | 点滅 | 各ボタンの上のランプが n 回ずつ点滅 | 少ない順 |
| 2 | 色の帯 | 別の壁に色の帯（左 → 右） | 帯の色の順 |
| 2 | 記号の列 | 別の壁の札に記号の並び | 札の並び |
| 2 | 言葉 | 札の言葉「空・森・炎・雪」 | 言葉が表す色の順 |
| 3 | 隣の部屋 | 手がかりの帯が隣の部屋にある | 隣の帯の順 |
| 3 | 二重の決まり | 色の帯 ＋「逆から」の札 / 点の数 ＋ 同数は台の高さ | 2 つの決まりを合わせた順 |

- 型・色・配置は seed で決める。ボタンと手がかりは壁に付けるので、どの大きさの部屋にも置ける
- 型と難易度の対応は 1 か所の表にまとめ、あとで入れ替えやすくする

## 5. ヒント

- 各部屋にヒント 1〜3。型ごとの文の型に、その部屋の具体（方角・色・記号）を入れて作る。文面は 1 ファイルにまとめて書き換えやすくする
  - 例（色の帯・北の壁）: ヒント 1「この部屋の飾りは、ただの飾りではない」/ ヒント 2「北の壁の色の帯と、ボタンの色を見比べよう」/ ヒント 3「帯の左から順に押す。最初は青」
- ヒント 3 は「決まりをはっきり言い、最初の 1〜2 手を明かす」（答えを全部は書かない）程度を想定
- 難易度 0 の部屋のヒントは、ボタンの場所を指す
- 解放: 制圧 50 部屋でヒント 1、75 でヒント 2、95 でヒント 3（全部屋に同時）。境目は定数と URL（`?h1=50&h2=75&h3=95`）で変えられるようにする
- 解放の瞬間に通知（「ヒント 1 解放」）を出し、タブレットのヒントのタブに新着の印

## 6. タブレット（Tab で出す・しまう）

- 見せ方は「確認したいこと 4」
- v2 の出す・しまう動き（持ち上げる弧・呼吸・歩く揺れ・振り向きの遅れ）と、壁に埋まらない重ね描きを参考に、このデモ用に小さく作り直す
  （v2 のタブレットはカメラ・SNS などと一体なので、読み込まずに作る）
- タブ: [1] MAP（既定）/ [2] HINT。数字キーかホイールで切り替え
- 出している間も歩ける・見回せる（ヒントと部屋を見比べられるように。v2 は視点を止めるが、ここは止めない案）
- MAP タブ
  - 全体マップ（北が上、100 部屋が収まる縮尺）・現在地と向き・扉
  - 色: 未踏破 = 暗い輪郭 / 踏破 = 水色 / 制圧 = 橙。難易度は踏破済みの部屋に ◆ の数で（見せ方は「確認したいこと 3」）
  - 進行率バー: 1 本のバーに踏破（水色）と制圧（橙）を重ねる（制圧 ≦ 踏破なので両方見える）。100 の区切り（1 部屋 = 1 %）。
    バーの上に「踏破 42 %」「制圧 18 %」、バーの下に 50 / 75 / 95 の目盛り（H1 / H2 / H3。届いたら点灯）
- HINT タブ: 今いる部屋の番号・難易度・踏破 / 制圧・ボタンの数、ヒント 1〜3 の枠（未解放は鍵と「あと n 部屋の制圧で解放」）
- ホログラム調の見た目: 暗く透ける板、シアンの細い線と橙の差し色、角の括弧、光のにじみ、走査線と軽いちらつき、出すときに走査線が広がって現れる。
  数字は等幅。フォントは端末の物（Mac は DIN Alternate とヒラギノ、Windows は Bahnschrift と游ゴシック）

## 7. デバッグ

- **次のヒント段階へ**: 制圧数を次の境目（50 → 75 → 95 → 100）まで上げる。未制圧の部屋を難易度の低い順（同じ難易度の中はランダム）に、
  今いる部屋を除いて制圧済みにする（制圧した部屋は踏破も立てる）
- **進行の初期化**
- 呼び出し: Esc の一時停止の画面の「デバッグ」、`N` キー（次のヒント段階へ）、コンソールの `debug.nextStage()` / `debug.reset()`
- ほかに: 今の部屋の答えを見る・番号の部屋へ移る・全部屋を踏破
