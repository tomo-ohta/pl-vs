## 2. 手法（段階 1）

| 特徴 | 手法 | 実装 |
|---|---|---|
| 色指定の 3 段（暗いラック・中間の壁・明るい床） | 色彩設計の段落とし（StyleMaterial）。色は --sample の値をそのまま | 床・壁・天井は部屋ごとの材質（`serverroom/looks.ts`）。小物と建具は **頂点の色 + 1 つの材質**（`mats.ts` の VcMats。色ごとに材質を分けず描く回数を抑える） |
| 機器の前面と無数の LED | 手続きのキャンバスの図柄（前面 16 種・背面 16 種。1U/2U のサーバー・スイッチ・ストレージ・パッチパネル・目隠し・空き）を色の図柄と光の図柄に同じ割り付けで描き、`emissiveMap` で光らせる。LED は同じ型の機器を積んだときの縦の点の列 | `atlas.ts`（参考画像は読まない） |
| ガラス扉（正面は暗く透け、斜めほど通路の明るさが映る・下ほど床が映る） | フレネルで不透明度と色を変える場面専用のシェーダー + 縦の映り込みの筋の図柄 | `glass.ts`・`atlas.ts` の makeGlassStreaks |
| 光沢の床の映り込み | 平面の鏡像（PlanarReflector）を床の材質の reflection で | 部屋ごとの強さ（0.3〜0.55） |
| LED・器具のにじみ | 光る板（unlit の頂点の色 ×2.4）+ ブルーム + ディフュージョン | style.post |
| 奥ほど霞む・床の近くが濃い（C） | 距離の霧。C は高さの減り方を付ける | 部屋ごとの見た目（`ROOM_STYLE`・styleZones） |
| 突き当たりの明るい面・床 | 灯りの光だまり（`ctx.addLamp`。四角・硬い縁、照らす箱 = 壁の面・扉の前の床） | `room.ts` |
| 太い筆の塊（serverroom-1） | 異方性クワハラ（半分の解像度・半径 4） | C の部屋の見た目だけ |
| 垂れたケーブル・ケーブルラック | 小物の道具の管（tube）・角の丸い箱で、はしご形の桁と桟・積んだ束 | `overhead.ts` |
| 吹き出しの床の板 | 透明の地に切れ込みの図柄を貼った板（映り込みには出さない層） | `atlas.ts` の makeGrille |

## 3. 建物と間取り図（段階 1.5）

**類型**: 通信ビルの 3 階のデータセンターのフロア（41 × 30 m）。根拠: 搬入 → 開梱 → サーバー室の動線、電源の系統（UPS → 分電盤 → ラックの PDU）、空調機は二重床の床下へ冷気を送る（コールドアイルの列の前に吹き出しの板）、ラック 幅 0.6 × 奥行き 1.1 m・42〜48U、コールドアイル 1.8〜2.6 m・ホットアイル 1.2〜1.5 m、床の板 0.6 m 角。

| 区画 | 内容 |
|---|---|
| サーバー室 A・B・C（各 7.2 × 16 m） | 参考画像 serverroom-2 / 0 / 1 の視点。コールドアイルを挟むラックの 2 列（背はホットアイル。側の壁に分電盤・電線管・縦のケーブルラック）。北の扉は通路の突き当たり、南の壁の西の端に空調機械室への扉 |
| 共用廊下（北） | 3 室・機械室・監視室・開梱室をつなぐ。扉の横にカードの読み取り機と室名の札、腰の保護の板、消火栓、監視カメラ、避難経路図。西の端は非常口（鍵）、東の端は事務所の棟（鍵） |
| 廊下の北 | 荷物用エレベーター（閉）・消火ガスのボンベ室（行き止まり）・UPS 室・蓄電池室・電気室 |
| 西の棟 | 開梱室（棚・作業台・組み立て中のラック・パレット）と荷捌き場（トラックの着く低い床 -1.1 m・荷台の高さの床・パレットラック・カゴ台車・2 t のアルミバン・ラップの巻き機・シャッター（閉）） |
| 東の棟 | 監視室（NOC。机の列・壁の大きな画面・時計・通信ラック）と、階段とエレベーターのホール（U 字の階段で踊り場 +2.25 m・上の階の扉の前 +4.5 m（鍵）） |

**視点の画角の確かめ**（`--plan`）: 3 視点とも画角は自分の部屋の中だけ（両側のラックの列と突き当たりの北の壁）。突き当たりは閉じた扉なので、扉の向こうの廊下は写らない（近づくと廊下の側へ開く）。
視点の後ろは同じ列が南の壁まで続く。参考画像の視点から写らない列の背・側の壁に作り込みを足した。

道順 20 か所（各部屋・振り返り 3・行き止まり 2・高い所 3（点検通路・踊り場・上の扉の前）・低い所 2（トラックの着く床・床下をのぞく点検口））。
`--reach serverroom` は 0 で終わる（全視点・全道順に届く。歩ける升目 8610）。

**判断の記録**（plan.ts の notes にも）: 部屋ごとに照明の色合いが違う（現実離れ。参考画像の色を優先）。床は廊下と同じ高さ（スラブを下げた二重床の想定）。serverroom-1 の床の暗い升は、点検口ではなくケーブルの切り欠き（0.9 × 0.3 m の細長い穴）として作り、床下 0.6 m と床下のケーブル・支柱を作った。板を 1 枚外した点検口と三角コーンは視点の後ろに置いた。

**2 回目に直したこと**:
- **ガラスの扉**（`glass.ts`）: 暗い青の色付きガラス（正面は中の機器と LED が透ける）+ 斜めほど淡い青の艶（フレネル）+ **向かいの列の映り込み**（映った視線を通路の幅だけ離れた向かいの面に当て、0.6 m ごとの扉・枠の縦の線・框・LED の点・ラックの上は天井の灯りの列・足元は床の明るさを手続きで描く。視線で動く）+ 縦の明るい筋（灯りの映り込みの図柄）。遠くの細かい模様は平均の色へ溶かす。中の機器は暗く（白い札の線を消し、前面の色を部屋ごとに暗く）、LED は明るく（2.6〜3.2）。ラックの壁の平均の明るさは参考画像と ±5 以内（中ほど・奥。手前は +3〜5 明るい）
- **床の映り込み**: 部屋ごとの強さ 0.5〜0.65・段に丸め（5 段）・ゆがみ 0.004・フレネル弱め。ラックの近くは鏡像で暗く、中ほどは灯りの映り込みで明るい斑。床の色は平均が変わらないように少し明るく。鏡像は場面に 1 枚（見えない部屋は描かないので重さは同じ）
- **serverroom-0 の天井**: 大きな光る器具をやめ、ルーバーの付いた 0.3 m の器具を 1.6 m おき（参考画像の z -7.0・-8.6・-10.2 に合わせた）と列の上 x ±2.2 に。通路の縁の上に設備の塊（箱の積み重ね・垂れたケーブルの輪・下りる電線管・低いラックと天井に近い細いラックの 2 段・束）を 0.5〜0.9 m おきに

カメラ: 消失点・画角・目の高さを振って構図 F が最大になる所を探した（例: A は消失点 x 711 → 703 で +1、画角 ±2° で −6〜−10、目の高さ ±9 cm で −9）。主な線（床と列の境目・扉の枠・天井の縁・吹き出しの板）は `-edges.png` で白く重なる。
**目標（半写実 ΔE ≤ 5.5・F ≥ 55）には届いていない**。理由: 参考画像の情報の大半が「数千の LED の点・ガラスの縦の筋・筆の跡」で、位置が 1 点ずつ合うことは無い（描画の点と参考の点が別の所にある → ΔE は 182×102 の画素ごとに大きく、輪郭は点の数だけ外れる）。
縮小して点を均すと ΔE は 3.5 前後（1/16）で、色と明暗の配置は合っている。構図 F は LED の点を減らすと上がり（+1〜2）、増やすと下がるので、点の密度は参考画像の見た目（縦の点の列）に合わせて止めた。

部屋ごとの色合い（`looks.ts`）: 霧の色・濃さ・始まる距離、床・壁・天井の 4 色、ガラスの色と不透明度・フレネル・床の映り込み、LED の明るさ、機器の前面の色（C は紺へ寄せる）、輪郭線の濃さ、後処理の彩度。

## 5. 写っていない所（段階 1.6）

語彙（参考画像の 3 つの大きさ）: 大 = ラックの列・ケーブルラック・ダクト・梁・下がり壁 / 中 = 盤・端子箱・還気の格子・照明・非常灯・掲示・画面 / 小 = LED・札・電線管・ケーブル・吹き出しの板の切れ込み。光は「暗い設備 + 点々と光るシアン + 明るい床」。

規則（`dress.ts`・`spaces.ts`。撮られる所だけを直さない）:
- **全部の壁**: 巾木・暗い腰の帯・見切り・横に走る電線管 2〜3 本と支持金物、決まった間隔（1.0〜2.0 m。扉と端は避ける）で 7 種（端子箱と電線管・還気の格子とコンセント・火災報知・掲示板または小さな盤・非常灯・縦のケーブルラック・立て管と弁）。機械の部屋と荷捌き場は壁ぎわの上にはしご形のケーブルラック
- **ホットアイル**: 分電盤（RPP）・縦の電線管・コンセントの帯。ラックの背の扉越しに背面の図柄（色つきのパッチケーブル・縦の PDU・ファン）
- **天井を見せる部屋**: はしご形のラック 2 本（色の束: 黒・青・黄・灰）・配管 2 本（赤い消火・青）と噴き出し口・ダクトと吹き出し口・吊りボルト、約 4.8 m おきの梁と壁の柱型
- **背の高い部屋**（荷捌き場・階段・空調機械室）は腰の上に波形の鋼板、監視室は吸音の板、扉の所は内張りを切る
- **床**: 部屋の種類で材質（廊下 = ビニルのタイル、電源の部屋と開梱室 = 床の板、監視室 = タイルカーペット、荷捌き場 = コンクリートの目地、ほか = 塗り床の目地）、盤・ボンベ・荷台の縁の前に黄と黒の縞
- **光**: 本物の器具の下に四角く硬い光だまり（照らす箱 = 部屋の内側）。部屋ごとに灯りを数え、見えない部屋の灯りは消す（目に近い 16 個の枠を壁の向こうに取られない）。サーバー室の外の段のしきい値を上げ、壁は陰の段・床と灯りの下だけ日なた

## 8. 依頼（共通の道具）

- `Lamp` に「点ける・消す」をまとめて扱う口（部屋ごとの灯りの組）。今は場面の中で `ctx.addLamp` を包んで部屋ごとに数えている
- `Prop.box` などの部品に頂点の色を直接渡す口（色ごとに材質を作らず 1 つの材質で描く）。今は場面の VcMats が「しるしの材質」を頂点の色に置き換えている
- 質感の物差しの無作為の場所: 参考画像が点の模様だらけの場面では、平らな面の多い付帯の部屋が常に「平ら」の印になる。点の模様を除いた指標（または 1/2 の大きさの細部）があると比べやすい
