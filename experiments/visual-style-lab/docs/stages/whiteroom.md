**描き方の型**: 上位 16 色 0.52〜0.57・平坦率 0.86〜0.89・面はほぼ平らで筆の跡の模様で色数が増えている → **段落とし（色指定）+ 筆の跡の模様**（docs/05 の「段落とし + 模様」）。半写実ではなく絵の具の色面。

**画像同士の関係と矛盾**: 3 枚とも「白い塗りの打ち放しの中庭・淡い緑の灰色・深い凹みの暗い緑」だが、0 は 3 階建ての壁に直接囲まれた中庭、1 は庇の並ぶ長い中庭、2 は平屋の回廊とテラスに囲まれた沈んだ中庭で、1 つの中庭にはまとまらない。日の向きも 0（左の後ろ）・1（ほぼ真上）・2（前の少し左）で合わない。空の色も 1 だけ壁より暗い。→ **同じ建物の別の中庭 A・B・C** にした（docs/06 の「区画を分けてそれぞれの画像を優先」）。

## 2. 手法（段階 1）

| 特徴 | 手法 | 実装 |
|---|---|---|
| 色指定の段（日なた・陰・深い凹み） | 色彩設計の段落とし（StyleMaterial）。面の色は中庭ごとの色の表（`PAL`）に --sample の値を直接。段のしきい値 [2.6, 0.62, 0.18]、日 1.4π・空 1.25 で「日なた / 陰」の 2 段がはっきり分かれるように（陰 F ≈ 0.32〜0.40、日なた ≥ 0.8） | `whiteroom/mats.ts`・`whiteroom.ts` |
| 縦の線が平行のまま見下ろす（あおりの建築パース） | カメラは水平のまま、写す範囲だけを上下にずらす（three の `setViewOffset` で大きな仮の画面の一部を描く）。参考画像の視点にカメラがある間だけ beforeRender で掛け、離れたら元に戻す。画素 ↔ 座標は `ShiftCam`（ViewCam の仮の画面を使って y をずらす） | `whiteroom/shiftcam.ts` |
| 乾いた筆の四角い跡・塗り直しの斑 | ワールド座標の行（床は横、壁は縦）に並ぶ矩形の跡を 2 つの大きさで重ね、端をノイズで欠く。面の色のむらは型枠の板・打設の区画ごと（3 回目の直しで、勝手な四角い斑と縦の垂れの筋をやめた。10 章）、緑 ↔ 灰の色み。陰の中だけ跡を強める（段落としの後の明るさで）。小さい跡は画素より小さくなると消す | `whiteroom/brush.ts`（StyleMaterial の onBeforeCompile に足す） |
| 近くで見える打ち放しの細部 | 型枠の締め付けの穴の並び（0.6 × 0.45 m）・床の目地（3 m）。画面で 1 画素より小さくなる距離で消す（参考画像の視点の距離では見えない） | `brush.ts`（ties・joints） |
| 濃い点・ひび | 升目ごとの短い線（flecks）。A の床が一番多い | `mats.ts` の `FLECK` |
| C の床の湿った斑 | ねじったノイズのしきい値（blotch） | `mats.ts` |
| ひさし・庇・開口の影の形（斜めの三角・平行四辺形） | 本物の日の影（影の地図 4096・影の縁のずらし 5 cm・段の境目のノイズ）。中庭ごとに日の向きと影の範囲を切り替える（区域。屋内プールの建築版と同じ） | `whiteroom.ts` の `SUN`・`ZONES` |
| 中庭ごとに違う空と空気 | 区域ごとの見た目（styleZones + 視点の style）と、自前の空のドーム（区域ごとに地平と天頂の色・筆の跡）。B は霧の色 = 暗い空の色で 38 m より向こうを空に溶かす | `whiteroom/sky.ts`・`whiteroom.ts` |
| 深い凹みの暗さ（回廊・ロッジア・庇の下） | 凹みの中の面は暗い材質（slot・loggia・under・deep）。日は形で遮る | `courtA/B/C.ts` |
| 窓の下の雨の垂れ | 細い窓ごとに暗い筋の板 | `courtA/B.ts` |

採用しない物（docs/05 と同じ）: カメラマッピング・SSR・体積の霧・TAA。後処理の線・ディフュージョンも使わない（参考画像に線が無く、ディフュージョンは暗い緑を持ち上げて色が合わなくなった）。

**矛盾の解き方と現実離れした所**（plan.ts の notes にも同じ）:
1. 3 枚 = 同じ建物の 3 つの中庭（上の表）。
2. 日の向き: A と C は同じ日（南西・高さ 60°）。参考画像 0 は北を、2 は西を見るので、0 では「左の後ろ」、2 では「前の少し左（逆光）」になり、どちらの陰の付き方とも合う。**B だけほぼ真上の日**（庇の影が庇の真下に落ちているため）。B は門の棟の通路と門扉で隔てられ、切り替わる所は見えない（現実離れ。記録）。
3. B の空だけ暗い灰青緑: B の区域の空のドームと霧の色。霧は 38 m から濃く、門の棟の向こうの A の棟は霧に溶ける（B の中を北へ歩けば A の棟が見えてくる）。
4. 参考画像 0 の北の棟の 1 階が周りと同じ向きなのに暗い → 凹み 2.2 m のロッジア（奥まで日が届かない）+ 暗い材質。
5. 参考画像 0 の西の棟の屋根の線が奥へ下がる → 折れ屋根（礼拝堂の棟の高い天井の名残とみなす）。床の影の幅が手前 1.2 m・奥 2.5 m に変わるので、手前（z > -8.8）は平屋。
6. 参考画像 2 の手前の淡い帯 + 暗い面は、視点の棟の外にある門の壁の上面と外の面（バルコニーの手すり壁とすると目が床から 3.5 m になり合わない）。外の面だけ暗い（北向きで苔むした面とみなす）。
7. 参考画像 2 の中庭の面の暗い三角・平行四辺形は、長く低い開口（上端 2 m）の奥の暗い回廊が手前の壁で隠れた形（上の縁が消失点へ向かう水平の線だった）。

## 5. 写っていない所（段階 1.6）

参考画像の語彙: 大 = 深い開口・袖壁・ひさし・庇・柱型・梁、中 = 扉・細い窓・灯り・ベンチ・腰掛け、小 = 筆の跡・濃い点・型枠の穴・雨の垂れ。決まり（どこにでも同じ）:
- 部屋（`interior.ts` の `buildRoom`）: 壁は外の材質の箱 + 内側の内装の板（腰壁 1.1 m の暗い塗り・上は漆喰）、3 m おきの柱型と天井の梁（濃い灰緑）、1.5 m の格天井、巾木・扉の枠・扉の横のスイッチ、高い所の換気口と額、4 m おきの天井の灯りと吊り下げの笠（高窓の明るい帯は 3 回目の直しで本物の窓に置き換えた。10 章）。灯りは**器具の真下の床だけ**に四角く硬い光だまりを落とし（照らす箱を床の高さに絞る）、壁と天井は灯りを受けない平らな塗り（段の境目のノイズも部屋の中は弱く細かく）。部屋の種類ごとの物（門番の部屋・通り抜けの間・集会室・図書室・食堂・工房・教室・寝室）
- 屋根のある歩廊（`dressWalk`）: 3 m おきの梁・6 m おきの灯り。参考画像から開口越しに見える回廊は梁も暗く、灯りは消したまま
- 外: C の棟の窓は 3.4 m おき、細い窓の下に雨の垂れ、前庭と中庭の写っていない所に植木鉢・洗い場・排水の格子・物置きの一角

## 9. 道具への依頼（core requests）

1. **あおり（シフト）レンズを ViewDef に**（例 `ViewDef.shiftY` = 地平線の画素）。今は場面の beforeRender で `setViewOffset` と画角・縦横比を差し替えている（`whiteroom/shiftcam.ts`）。撮影・比べ・`--plan` の扇はそのままで動くが、App が持つ方が安全
2. **区域ごとの空**（`StyleZone` に空の色・筆の跡）。今は自前の空のドームを beforeRender で切り替えている（`whiteroom/sky.ts`）
3. **区域ごとの日の向きと影の範囲**（屋内プールと同じ処理を場面ごとに書いている）
4. `--quality` の無作為の場所が、間取り図の「閉じた塊」の中の部屋の点を塊の名前で数える（空間の順で先に当たる方。部屋を先に並べて回避した）。画角 60° の撮影と参考画像の視点（狭い画角）の比べ方の差も見直したい
