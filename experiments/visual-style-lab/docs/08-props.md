# 小物の作り込み（最初から作り込む手順）

場所の「建物」（部屋・廊下・柱・梁・窓）は参考画像に合わせて作り込めたが、**小物**（自販機・車・棚の中身・ベンチ・植木など）は
箱を数個重ねただけ・箱に絵を貼っただけの物が残っていた（駅の車は箱 3 つ、プールの自販機は白い箱 1 つ、倉庫の棚の中身は
大きさの違う無地の箱の積み重ね）。部屋の広さの数値（docs/07 の質感の物差し）は画面全体の情報量を見るので、
箱に絵を貼った物でも数値は満たせてしまい、**近くで見たときの形** を確かめる段が無かった。

この段では、小物を最初から作り込むために、次の 3 つを使う。

| | 中身 |
|---|---|
| 小物の道具 `src/props/kit.ts` | 角の丸い箱・円柱・回転体（輪郭を回す）・押し出し（輪郭に厚み。縁の丸みを付けても寸法は変わらない）・管・楕円体・輪・板。物ごとの局所の座標（正面 +z・床 y = 0）で書き、**色（sRGB）と種類（ふつう・光る・ガラス）** で頼む |
| 場所ごとの材質の作り方 `PropMats` | 色と種類から、その場所の絵柄の材質（色彩設計の段落とし・面ごとの塗り・駅の材質）を返す。同じ色は同じ材質なので、材質ごとにまとめて描かれる（描画の回数が増えない） |
| 共通の小物 `src/props/lib/` | 飲料・お菓子の自動販売機・券売機・冷水機・軽自動車（ワゴン・低い型）・軽トラック・自転車・スチール棚と中身（段ボール・収納箱・ファイル・畳んだタオル・瓶・ビート板・紙の束）・積んだ段ボール・ベンチ（板・1 枚板・待合いの椅子）・椅子（積み重ね・事務椅子）・鉢植え・ごみ箱（丸・分別）・消火器 |
| 見本帳 `props.html` | 小物を 1 列に並べ、物ごとに「近く（斜め前）」と「4 m 前後（正面寄り）」から撮る。`node tools/capture.mjs --page props.html --tour common`（場所ごとの見本帳は `--tour <場所>`） |

## 手順

1. **小物の一覧**: 場所ごとに、置いている小物を全部書き出す（何を・どこに・いくつ・どの距離で見られるか）。
   今の作りを「そのままでよい / 作り直す / 共通の小物に置き換える」に分ける。よく目に入る物（道順・無作為の場所の撮影に写る物）から
2. **実物を調べて表にする**: 寸法・主な部位・材質の色。例: 軽自動車 = 全長 3.39 m・全幅 1.47 m、ボディの面の折れ・前のガラスと柱・
   ライトとグリル・バンパー・ナンバー・ミラー・ドアの継ぎ目と取っ手・輪の穴・タイヤとホイール
3. **作る**: 道具で、部位ごとに形を置く。決まり:
   - 実寸。厚み（板は 1〜3 cm、柱は太さを持つ）。縁は少し丸める（`r` / `bevel` 0.5〜3 cm）
   - **近く（1.5 m）で見て何か分かる**。見分けの付く部位を必ず付ける（段ボール = ふたの合わせ目・テープ・ラベル、ファイル = 背のラベル・指穴、瓶 = 肩・首・ふた）
   - **場所の絵柄に合わせる**: 色はその場所の色の表から。平らな色面の絵柄なので、模様を細かく描き込まない（形の部位で見せる）。
     小物の材質は段の境目のノイズと影の升目を切る（丸い面・小さな面でまだら・煙のような汚れにならないように。`styleMats` の既定）
   - 小さな部品（取っ手・ミラー・ボタン）は影を落とさない（`shadow: false`）。当たり判定は外形の箱だけ
   - 同じ物のばらつき（色・寸法・向き・中身）は物ごとの乱数（`p.r()`）で
4. **見本帳で確かめる**: 近くと 4 m の 2 枚を見て、形・寸法・部位・絵柄を直す
5. **場面に置く**: 決まり（部屋の種類ごとの置く物）で置く。参考画像の視点に写る物を変えたら、元の版との比べ（ΔE +0.5・構図 F −3）を確かめる
6. **重さ**: 同じ色は同じ材質にまとめる（色の種類を増やしすぎない）。1456×816 で 1 フレーム 8 ms 以下

## 合格の条件

| 確かめ | 合格 |
|---|---|
| 見本帳（近く） | どの小物も何か分かる。実寸。主な部位がある。箱だけ・絵を貼っただけの物が無い |
| 見本帳（4 m） | 輪郭と色が場所の絵柄に合う（細かすぎない・浮かない） |
| 場面 | 道順・無作為の場所の撮影で、棚の中身・機械・乗り物・家具が「何か分かる」。無地の箱の積み重ねが無い |
| 参考画像の視点 | 元の版との比べに合格（ΔE +0.5・構図 F −3 以内） |
| 歩いて行けるか・重さ | `--reach` が 0 で終わる。視点と道順で 8 ms 以下 |
