# 写っていない所の作り込み（建築版の仕上げ）

建築版（[06-architecture.md](06-architecture.md)）で、参考画像の視点の外も建物として自然につながった。
ただ、写っていない所は参考画像の視点より **形・材質・模様・光** が素っ気なかった。
この段では「参考画像の雰囲気と質感を全体で再現する」を最優先に、写っていない所を参考画像の視点と同じ仕上がりにする。

## 1. 何が素っ気ないのかを言葉と数値にする

### 目で見た共通の弱点（5 か所の道順の撮影から）

| 弱点 | 参考画像では | 写っていない所では |
|---|---|---|
| 壁の情報量 | 貼り紙・掲示・スイッチ・柱型・枠・配管・汚れが、大中小の大きさで並ぶ | 腰壁の上が何も無い面 |
| 天井 | 照明の器具・換気口・感知器・カメラ・梁・段 | 平らな面に照明 1 種類 |
| 光 | 日なたと陰の帯・光だまり・明るい開口・暗い奥 | 部屋の中が一様な明るさ |
| 面の色 | 同じ色の面でも少しずつ違う（板・タイルごと） | 1 面 1 色 |
| 場所の「らしさ」 | プールなら天窓の日なたとタイルの塊、駅なら霧と蛍光灯 | 付属の部屋が「どこにでもある白い部屋」 |

### 質感の物差し（`--quality`）

参考画像・参考画像の視点の描画・道順・無作為の場所を、**同じ数値**で測る（`src/core/Quality.ts`）。
画素の位置は比べない（構図が違うので）。728×408 の OKLab で:

| 数値 | 何を見るか |
|---|---|
| 細部 detail | 細かい輪郭の割合（貼り紙・目地・ちぎれた縁・小物） |
| 形 shape | 1/8 の大きさでの輪郭の割合（家具・柱型・枠・器具の多さ） |
| 明暗 light | 1/32 の大きさの明るさのばらつき（日なたと陰・光だまり・暗がり） |
| 幅 contrast | 明るさの 5〜95 % の幅 |
| 平ら flat | 何も無い画素の割合 |
| 色差 palette | 参考画像の 16 色までの平均の色差（参考画像に無い色が出ていないか） |

**基準は「参考画像の視点の描画」**（利用者が見て良いとした所）。道順と無作為の場所の中央値が、基準の中央値の 0.85〜1.35 倍に入るのを目安にする。
数値は「弱い所を見つける」ためのもので、意味の無い粒やごみで数値を上げない。最後は参考画像と並べて目で決める。

```
node tools/capture.mjs --page arch.html --quality <場所> [--seed 2] [--n 18]   … 一覧（-tour.jpg・-random.jpg）と数値
node tools/capture.mjs --page arch.html --shot <場所> x,y,z,yaw,pitch          … 1 枚と同じ数値（直しながら）
```

### 無作為の場所（`randomStops`）

道順は作った人が選ぶので、得意な所に偏る。歩いて届く所（`reach`）を間取り図の場所ごとに分け、場所を順に選んで、
その中の無作為の点から開けた向き（壁まで 2.5 m 以上）を向いて撮る。種（`--seed`）を変えると別の場所になる。
担当は種 1・2 で確かめ、統括は担当が見ていない種で確かめる（**規則で直したか、撮られる所だけ直したか**が分かる）。

## 2. 直し方（規則で、どこにでも）

撮られる所だけを直さない。部屋の種類・面の種類ごとの「決まり」を作り、全部の部屋に当てる。

1. **参考画像の語彙を書く**: 大（柱型・梁・枠・開口・段）・中（照明・換気口・掲示板・配管・スイッチ・手すり・家具）・
   小（紙・シール・擦れ・染み・目地・ごみ・塗りのちぎれ）の 3 つの大きさで、何がどのくらいの密度で並ぶか（壁 10 m あたり何個、など）。
   光の言葉（帯の位置・明るい開口・光だまり・暗がり）と材質の扱いも
2. **形**: 巾木・枠（奥行きのある額縁）・柱型・手すり・天井の器具と段。箱の部屋の中に「建物の部材」を入れる
3. **材質・模様**: 板・タイルごとの明るさのばらつき・擦れ・染み・雪や水の分布を建物に沿わせる（開口の近く・壁ぎわ）
4. **光**: 本物の器具の下に灯り（`ctx.addLamp`）、窓・天窓からの日なた、暗い奥・明るい開口。場所の光の言葉に合わせる
5. **小物**: 部屋の種類ごとの置く物の決まりを広げ、壁沿いに小物を並べる決まり（扉・窓を避ける・参考画像のように群れる）

場所の「控えめさ」も守る（淡色の廊下は散らからない場所。足すのは値の段と、ありそうな器具）。

## 3. 灯りの光だまり（`src/render/Lamps.ts`）

写っていない部屋の光を一様でなくするための道具。

- `ctx.addLamp({ pos, radius, intensity, box, yaw?, square?, hard?, down?, color?, shadow?, on? })`
  - `yaw` = 照らす箱を中心のまわりに回す（斜めの建物の部屋）
  - `square` = 四角い光だまり（天窓・四角い器具の形）。`hard` = 縁を硬く切る。場面の影の升目（`shadowQuant`）があれば縁も升目に沿って段になる（プールの角ばった日なた）
- 色彩設計の材質（`StyleMaterial`）の **照明の倍率に足す** ので、灯りのまわりで段（陰 → 日なた → ハイライト）が切り替わり、
  段の境目は場面の段と同じノイズでちぎれる（塗りの光だまり）。塗りの材質（`PaintMaterial`）も、色を明るくして縁をちぎる
- 影は付けない代わりに **照らす箱**（部屋の内側）を決める。箱の外へは届かないので、壁の向こうの部屋へ漏れない
- `shadow`（既定 0.8）: 場面の平行光源の影をこの灯りにも効かせる。室内の場面の平行光源は天井の明かりの代わりなので、
  家具の下・棚の陰の影が灯りで消えない。屋外の街灯は 0
- 毎フレーム、目に近い 16 個だけを使う（照らす箱までの距離の順。箱まで 24 m（`LampSet.maxDist`）より遠い灯りは送らない）。区域の見た目（`StylePreset.lamps`）で強さを変えられる

空だけを明るくする: `SkyOptions.gain / tint / tintAmount / horizonBlend`（物に掛かる霧の色は変えずに、空のドームだけを明るく・色を寄せる。
参考画像の「明るい空の端」を、視点の外の空でも出す）。

採らなかった物: 画面の空間で求める遮蔽（SSAO）— 参考画像の絵には隅の暗がりのぼかしが無く、絵の様式から外れる。
焼き込みの光の格子（irradiance volume）— 壁の厚さより升目が粗いと隣の部屋の光が漏れる。

## 4. 合格の条件（場所ごと）

| 確かめ | 合格 |
|---|---|
| 参考画像の視点 | 元の版との比べに全視点で合格（ΔE +0.5・構図 F −3 以内）。仕上げで視点の見た目を変えない |
| 歩いて行けるか | `--reach` が 0 で終わる |
| 重さ | 視点と道順の全部で 1456×816 で 8 ms 以下（`--perf`・`--tour --perf`） |
| 質感の物差し | 道順と無作為（種 1・2・統括の種）の中央値が基準の 0.85〜1.35 倍（細部・形・明暗・幅）。印の付く撮影は 2 割程度まで |
| 目で見る | どの撮影も参考画像と同じ場所に見える（色・段・線・空気・作り込み）。何も無い箱・裸の壁・ハリボテ・継ぎ目・縞・壁を抜ける光が無い |

## 5. 試した結果（2026-10-07。5 か所を並行の担当で）

数値は「写っていない所 ÷ 参考画像の視点の描画」の中央値（細部 / 形 / 明暗 / 幅）。直す前は種 1、直した後の無作為は**担当が一度も見ていない種 7**。

| 場所 | 道順（直す前 → 後） | 無作為（直す前 → 後） | 印の付いた道順 | 視点の重さ（前 → 後） |
|---|---|---|---|---|
| 病院の病棟 | 0.89 / 0.81 / 1.12 / 0.99 → 1.09 / 0.94 / 1.17 / 1.03 | 0.84 / 0.79 / 1.04 / 0.96 → 1.11 / 0.86 / 0.85 / 0.94 | 11/30 → 2/30 | 3.9〜4.1 → 4.7〜5.1 ms |
| 霧の駅 | 0.99 / 0.70 / 0.79 / 0.75 → 1.01 / 0.84 / 0.81 / 0.78 | 0.91 / 0.62 / 0.88 / 0.90 → 1.00 / 0.71 / 0.87 / 0.84 | 7/18 → 2/18 | 4.6〜6.4 → 4.6〜6.3 ms |
| 淡色の廊下 | 0.94 / 0.87 / 0.74 / 0.64 → 1.10 / 1.02 / 1.02 / 0.89 | 1.12 / 0.89 / 0.70 / 0.61 → 1.12 / 1.00 / 0.92 / 0.92 | 13/27 → 9/28 | 2.0 → 3.8 ms |
| 校舎の間 | 0.57 / 0.88 / 0.63 / 0.63 → 0.80 / 1.10 / 1.01 / 1.04 | 0.72 / 0.89 / 0.79 / 0.74 → 0.95 / 1.02 / 1.28 / 1.30 | 17/18 → 12/18 | 2.7 → 4.3 ms |
| 屋内プール | 0.86 / 0.60 / 0.45 / 0.50 → 1.08 / 1.00 / 0.77 / 0.85 | 0.78 / 0.55 / 0.38 / 0.40 → 1.16 / 0.99 / 0.79 / 0.88 | 24/32 → 6/32 | 3.5〜4.7 → 4.4〜6.4 ms |

- 参考画像の 14 視点はすべて元の版との比べに合格のまま（病院・駅・淡色の廊下・校舎の間は直す前と画素がほぼ同じ）。元の版（`index.html`）は 14 視点とも数値が変わらない
- 全視点・全道順へ歩いて届く（プールの洞窟の水路の中だけ「泳げば届く」。視点は泳がずに届く）
- 道順の重さの最大: 病院 5.6・駅 7.5・淡色の廊下 4.7・校舎の間 5.6・プール 6.6 ms（1456×816。8 ms 以下）

### 場所ごとにしたこと（要点）

| 場所 | 形 | 材質・模様 | 光 | 小物 |
|---|---|---|---|---|
| 病院 | 背中側の柱型・手すり・天井の器具 | 区域ごとの壁の擦り傷・足元のちぎれた帯 | 階段の影の帯・窓の下の日なた（B） | 壁を探る道具（光線で空いた壁を探し、参考画像の視点から見える所には置かない）で、扉の脇のスイッチ・貼り紙の群れ・掲示板・警報ボックス・床の紙くず |
| 駅 | 待合室の柱型と梁・階段の段鼻 | 濡れた床の映り込み・タイルの染みの筋・トタンのさび・水たまり | 部屋の箱だけを照らす蛍光灯の光だまり（駅専用の材質に足した） | 待合室のロッカー・掲示、地下道の手すり、ホームの待避所、野原の水路・茂み・小屋（90 m ごとにまとめて描く） |
| 淡色の廊下 | 柱型・梁・扉の見込み・階段の手すり | 窓のある壁は 1 段暗く・腰壁は静かに（白は上端と床ぎわだけ） | 窓の前の床の光だまり | スイッチ・コンセント・換気口・部屋ごとに暗い低い棚 1 つ |
| 校舎の間 | 遠くの家並み・向かいの建物の凹凸 | 窓ガラスの映り込み（空と木の塊・上の階ほど多い）・目地・雨の筋 | 光線で求めた日なたと木漏れ日・空だけを明るく（`SkyOptions.gain`） | 外壁の配管・室外機・メーター、地面の蓋・ひび・落ち葉、廊下と教室の掲示 |
| プール | 部屋ごとに段の付いた梁・柱型・格天井の天窓 | 陰の色を参考画像から・深い青緑の腰の帯・扉の見込み | 天窓からの日なた（升目の段の縁）・四角く硬い灯り（`square`・`hard`）・ホールから見た部屋は陰の色 | 家具の下の塗りの接地影 |

### 分かったこと

- **数値で弱い所を見つけ、目で直す**: 質感の物差しは目で見た印象とよく合った（プール・校舎の間が一番素っ気ない、病院が一番近い）。ただ数値だけを追うと意味の無い飛沫が増える（淡色の廊下の腰壁で一度起きた）。最後は参考画像と並べて目で決める
- **担当が見ていない種で確かめる**: 担当は種 1・2 で直し、統括は種 3〜7 で確かめた。どの場所も見ていない種で同じ程度の数値が出た（撮られる所だけでなく決まりで直せている）
- **参考画像の視点から見える所には足さない**: 病院・駅・校舎の間の担当は、参考画像のカメラから見えるかを調べる道具（目からの見通し）を作り、見える所には何も置かなかった。視点の画素は変わらない
- **場所の光の言葉を部屋にも持ち込む**: プールの付属の部屋は「天窓からの日なた・タイルの升目に沿った縁・深い青緑の陰」を入れると、同じ建物に見えるようになった
- **場所の控えめさは守る**: 駅の野原は参考画像どおり何も無い草原のまま（形の数値は低いまま）。淡色の廊下は散らからない
- 灯りの光だまりは、丸いとアメーバのような塊になる。参考画像に合わせて四角く・硬く・升目に沿わせる（`square`・`hard`）

### 残っている弱い所

- 校舎の間: 窓を正面から見た所と室内の道順は、細部の数値が低め（0.80）で「平ら」の印が多い
- 駅: 野原を向いた所は形の数値が低い（参考画像の控えめさを守ったため）。階段室の 1 か所は暗いまま
- プール: 参考画像の視点の無いホール（D の南・E の 25 m・B の北西）は明暗が少し足りない（0.77〜0.79）
- 淡色の廊下: 奥のホールは参考画像の明るい奥そのものなので、明るさの幅が狭いまま
- 重さは各場所で約 1〜2 ms 増えた（8 ms 以下には収まる）。駅の道順の重い所は 7.5 ms
