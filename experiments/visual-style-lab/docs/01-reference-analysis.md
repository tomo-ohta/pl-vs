# 参考画像の分析（言語化）

対象: `public/refs/` の 14 枚（1456×816・16:9）。生成 AI の出力で、題は「様式化した 3D アニメ風探索ゲームの一人称スクリーンショット」など。
5 つの場所に分かれる。

| 名前 | 枚数 | 場所 |
|---|---|---|
| station-0〜3 | 4 | 霧の中の乗り換え駅のホーム |
| pool-0〜3 | 4 | 白い正方形タイルの屋内プール群 |
| corridor-0〜3 | 4 | 病院（学校）の廊下。突き当たりに赤い扉 |
| pastel-0 | 1 | 見覚えのある空っぽの廊下（淡色） |
| alley-0 | 1 | 校舎と校舎の間の細い通路 |

数値は最初は一時の解析スクリプト（元の PNG）で測った。今は `node tools/capture.mjs --analyze <場所>` で同じ物が出る（JPEG なので平坦率は少し低く出る）。L・C は OKLab の明度・彩度（L は 0〜1）。
「平坦率」= 隣の画素との明度差が 0.004 未満の画素の割合。「上位16色」= 5 bit に丸めた色のうち多い順に 16 色が占める面積。

## 1. 全体に共通する特徴

1. **色数が少なく、彩度が低い。** 平均の彩度 C は 0.02〜0.06（写真なら 0.08〜0.15 程度）。どの絵も緑みの青〜黄緑の狭い色相帯に収まり、
   アクセントは 1 色だけ（廊下の珊瑚色の赤い扉 `#b86368`〜`#c97c6e`、駅の黄色い点字ブロック）。
2. **面が平ら。** 平坦率は廊下 0.83〜0.87、淡色廊下 0.87、プール 0.59〜0.74、駅 0.62〜0.74、通路 0.64。
   壁・床・天井は 1 面がほぼ 1 色で、光は 2〜4 段の明るさの差で表す。テクスチャの細かい模様は無い（プールのタイル目地だけが例外）。
3. **光と影の境目がギザギザ（ちぎった紙・切り絵）。** 幾何学的な影の線ではなく、不規則で欠けたような縁。
   Photoshop の「カットアウト」フィルタ、または「色の段数を落としてから中央値でならした」ような形。
   廊下では幅木のまわり・床の接地影・壁の白いかすれ、淡色廊下では床と壁の下の白い塗り残しのような斑、駅では水たまりの縁に出る。
4. **奥ほど明るく淡い（空気遠近）。** 廊下の突き当たり・駅の霧・通路の奥の建物。暗い手前と明るい奥で奥行きを出す。
5. **線は少ない。** 輪郭線は全部ではなく、物の外形や接地の所にだけ短く入る。色は黒ではなく暗い青緑（`#2d373c`・`#172831`・`#294349`）。
6. **小物は記号的。** 掲示物は白い長方形に灰色のくねった線。スイッチは小さい四角。カートは箱と車輪。
7. **カメラは人の目の高さ（1.5〜1.7 m）、水平に近い一点透視が多い。** 廊下は少し見下ろす（消失点が画面中央より上）、駅は少し見上げる（地平線が中央より下）。

## 2. 場所ごとの特徴

### 2.1 駅のホーム（station-0〜3）

- 見た目: アニメ映画の背景（新海誠作品のような）に近い、半写実の 3D。4 場所の中で一番「普通の 3D 描画」に近く、色の段数落としは弱い。
- 色: 色相 193°〜205°（シアン寄りの青緑）。霧は `#c0f5ec`〜`#ddfdf9`（L 0.91〜0.97）、上屋の下の暗部は `#0d232b`〜`#15333e`（L 0.23〜0.31）。
  明るい霧と暗い上屋の対比が強い（p5 L 0.23 / p95 L 0.95）。画面の上 1/4 は暗い上屋、中央の帯が霧で一番明るい（行ごとの明度 0.30 → 0.89 → 0.33）。
- 霧: とても濃い。50〜100 m で架線柱がほぼ消える。空と地面の境目も霧色に溶ける。霧は均一ではなく、地面近くがわずかに濃く、上方はわずかに青みが強い。
- 照明: 上屋の裏の蛍光灯（細長い光る板、白〜淡い黄緑）。周りに柔らかいにじみ（ブルーム）。上屋の下は暗く、柱・ベンチは逆光のシルエット。
- 床: 濡れたコンクリート。不定形の水たまりが鏡のように霧と光を映す（水たまりの縁はくっきり・ギザギザ）。水たまりの外は暗くつやが少ない。
  ベンチの映り込みは縦に少し伸びる。
- 線路側: 黄色の点字ブロックの帯（ホームの縁から 0.8〜1 m）、白い縁の線。線路のバラストと枕木、レールの細い光。
- 遠景: 架線柱（門型・トラス）、電線、低い倉庫、草原。すべて霧で薄れる。
- 構造物: 上屋は鉄骨の梁とトラス、柱は H 形鋼にコンクリートの台座、配管・ケーブル。ベンチは 2〜6 人掛けの背付き座席（樹脂）。
  station-2 は低い視点（線路の高さ）から見た島式ホームの小さな上屋（T 字形の屋根・中央の柱・小屋・時計・案内表示）。
  station-3 は長い上屋の下の中央柱列と、左右の別ホームの小さな上屋。

### 2.2 屋内プール（pool-0〜3）

- 見た目: 白いタイルの巨大な柱・梁の森と、その間を流れる浅い水路。強い日差しが天窓から入り、長くくっきりした影を落とす。
  pool-0 は比較的写実（光の帯・反射）、pool-1〜3 は段数を落とした絵（平らな色面）。
- 色: 色相 174°〜186°（青緑）。日なたのタイル `#eef4e3`〜`#f7f5e9`（L 0.95〜0.98）、日陰のタイル `#9bb3a4`〜`#a9c3b4`、
  深い陰 `#274348`〜`#39666b`、水 `#2f5e61`（深い所）〜`#73dbcb`（浅く光る所）。
- タイル: 一辺 20〜30 cm の正方形、目地は細く少し暗い。床・壁・柱・梁すべてがタイル張り。
- 形: 柱・梁は箱の積み重ね。角が階段状に欠けた（ボクセルのような）形が多い。天井は格子の天窓（ガラスと細い桟）。
- **影の縁がタイルの升目に沿って階段状になる**（pool-2・pool-3 で顕著）。日が当たるか当たらないかが「タイル 1 枚単位」で決まっているように見える。
- 水: 鏡のような反射が 2〜3 段の平らな色面に分かれる（柱の白い映り込みがちぎれた形で揺れる）。
  底のタイルが透けて見え、浅い所は明るい青緑、深い所は暗い青緑。光の帯（コースティクス）がまだらに出る。
- 空気: わずかに白くかすむ（奥の柱が淡くなる）。

### 2.3 病院・学校の廊下（corridor-0〜3）

- 見た目: 平らな色面のベクターイラスト風（フラットデザイン + セル調）。4 枚とも突き当たりに珊瑚色の赤い扉（両開き 3 枚・片開き 1 枚）。
- 色: 色相 120°〜170°（セージグリーン〜青緑）。壁の明るい面 `#c4c9a4`〜`#e3eed0`、壁の陰 `#889d89`〜`#7fa496`、
  床 `#7e998b`（暗い床）または `#e3eed0`（明るい床）、扉 `#b86368`〜`#c97c6e`、線と幅木 `#2d373c`〜`#4a544d`。
  上位 16 色で面積の 83〜90 %（強い段数落とし）。
- 光: 天井の蛍光灯（白い横長の箱）。光の段は 2〜3 段。柱の側面・壁の奥まった所が 1 段暗い。床の光は窓や照明の下に平らな明るい四角として出る。
- 縁: 幅木は暗い青緑の帯で、上下の縁がちぎれている。床の接地影は 1 段暗い帯。壁には白い短い傷・欠け（かすれ）が点々とある。
- 線: 物（カート・ポール・扉・掲示板）の外形に細い暗い線。壁と床の境目は線ではなく暗い帯。
- 小物: 掲示板（コルク色の板に白い紙）、張り紙（白い紙に灰色の文字のくねり）、手すり、白いポール（ベルトパーティション）、カート（箱型・車輪 4 つ）、
  ごみ箱、天井の監視カメラ、非常口の表示、スイッチ、消火器の箱（赤）、支払い端末のような機械。
- 天井: 灰色がかった緑の平面（corridor-2 は格子の天井板）。蛍光灯と監視カメラが中央に並ぶ。
- 柱: 廊下の両側に壁から出っ張った柱型が 2〜3 m おきに並び、その間に窓（右側）や扉がある。

### 2.4 淡色の廊下（pastel-0）

- 見た目: 4 場所の中で最も平ら。ほぼ影の無い淡いセージ・クリーム・灰青の色面だけ。線はほとんど無い。
- 色: 彩度 C 0.021（ほぼ無彩色）。`#dde4d7`・`#bac7bc`・`#ced4c4`・`#a7b8b2`・`#f4f7eb`。5 bit で 415 色しかない。
- 床と壁の下に、白い塗り（雪・粉・塗料のような）の斑が広がる。縁は筆でちぎったような形。
- 壁は上が淡い緑、腰から下が少し暗い灰青の 2 色（腰壁）。
- 廊下は奥へ続き、左右に壁の出っ張りと扉が並ぶ。天井は明るい灰緑で、蛍光灯は小さな白い長方形。
- 奥が白くかすむ（突き当たりは白い扉）。

### 2.5 校舎間の通路（alley-0）

- 見た目: 暗い青緑のセル調。両側に大きな窓の並ぶ校舎（5〜6 階建て）が迫り、空はほとんど見えない。
- 色: 色相 220°（青寄り）、平均明度 0.34。暗部 `#0a1c21`〜`#17343d` が 70 %、奥の建物と空 `#bfeed6`（L 0.91）が 5 %。
- 窓: ガラスに木の葉の影が映る（暗い緑の葉の塊）。窓枠は暗く、ガラスはやや明るい青緑。
- 奥: 突き当たりに木（明るい緑の葉）と、白く霞んだ高い建物。明るい奥と暗い手前の対比。
- 地面: アスファルトの細い道、白線 1〜2 本、側溝。日の差し込みが床に 1〜2 か所、明るい平らな四角として出る。

## 3. 実装への読み替え（要点）

| 特徴 | 実装で必要なこと |
|---|---|
| 色数が少ない・色指定どおり | 物ごとに「日なた・陰・暗部」の色を参考画像から直接指定する（アニメの色彩設計の「ノーマル色・影色」）。照明は段を選ぶためだけに使う |
| 光の段 2〜4 段 | 照明の明るさを段に丸める（トゥーン）。段の境目は少しだけぼかす |
| ギザギザの境目 | 段の境目をワールド座標のノイズでずらす（カメラが動いても模様が泳がない） |
| 影の縁がタイル単位（プール） | 影を調べる位置をタイルの升目の中心に丸める |
| 奥が淡い | 距離と高さの霧（指数）。霧の色は空と同じ |
| 線が少ない・暗い青緑 | 深度と法線の段差から線を出す後処理。物ごとに線の有無と太さ、ノイズで途切れさせる |
| 濡れた床・水 | 平面の鏡像（反射用のカメラ）をノイズの形の水たまりの中だけに出す。プールは反射を段に丸める |
| 蛍光灯のにじみ | 光る板 + ブルーム |
| 平らな色面・絵の具の塊 | 必要に応じて異方性クワハラフィルタで細部をならす |
| 小物は記号的 | 箱・円柱の組み合わせ + 手描き風のテクスチャ（キャンバスで作る） |
