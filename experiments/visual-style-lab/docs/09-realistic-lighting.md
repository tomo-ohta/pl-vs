# リアルな照明（ボタン 1 つで試す）

今までの見た目（色彩設計の段落とし・クワハラ・線・塗りの光だまり）は絵画的なので、もう少し写実寄りの照明も試せるようにした。
**場面の作りはそのまま**で、照明の見せ方だけを切り替える。切っているときは今までの描画と同じ（材質の計算も画面の処理も変わらない。
元の 14 視点・2 つ目の組の 17 視点とも、切った状態で数値が変わらないことを確かめた）。

| 入れ方 | 中身 |
|---|---|
| パネル | 「リアルな照明（J）」のボタンで入り切り。項目ごとの強さのつまみと「場面の既定に戻す」 |
| キー | J |
| URL | `?real=1`（入れる）・`?rset=ambient=0.3,shafts=2,autoExposure=false`（値の上書き） |
| 撮影 | `node tools/capture.mjs --page arch.html <場所> --params 'real=1'` |
| コード | `src/render/Real.ts`（設定・場面ごとの既定）・`src/render/RealPost.ts`（画面の処理）・`StyleMaterial` / `PaintMaterial` / `Lamps.ts` の `uReal` の分かれ道 |

## 1. 何を「リアル」にしたか（手法）

### 光源の近くが明るく、光源の無い所は暗い（材質）

| 手法 | 中身 | 出典・考え方 |
|---|---|---|
| 段落としを止める | 照明の倍率を段に丸めず、なめらかな陰影にする（影の升目・ちぎれ・霧の段も止める） | 色彩設計の段（アニメの影色）をやめて、物理的な陰影へ |
| 環境光を弱め、直接光を強める | 半球光（空・照り返し）を 0.4 倍、日光・スポットを 1.25 倍。光源の当たらない所が暗く落ちる | 写実的な照明の明暗比（直接光と間接光の比）を大きくする |
| 距離の 2 乗で弱まる灯り | 灯り（`ctx.addLamp`）を「中心で平ら」から「距離の 2 乗で弱まり、届く距離の端で 0」に。届く距離は 1.6 倍 | Karis 2013「Real Shading in Unreal Engine 4」の窓付きの逆 2 乗の減衰 |
| 光る面を HDR へ | 照明を使わない白に近い明るい面（照明器具・画面）と、材質の emissive を 3 倍に。ブルームで光る（海・空の大きな面は持ち上げない） | 光源は画面の白（1.0）より明るい。HDR の値があるからブルーム・グロウが出る |
| 照明器具を灯りにする | 照明を使わない白に近い小さな面（天井の蛍光灯・パネル・ランプ）を、つながった三角形の塊に分けて 1 つずつ見つけ、その下に灯り（`realOnly`）を置く。照らす箱は当たり判定の壁まで（壁の向こうへ漏れない）。入れた時に場面ごとに 1 回（0.1〜1.7 秒） | 光る物があればその近くが明るい、を場面のファイルを直さずに |
| 陰に空の色 | 環境光に場面の空（霧の天頂）の色を 6 割帯びさせる（屋外の陰は空の青み・場面の色を残す） | 天空光の色。陰の色彩設計の代わり |

### 空気の光（画面の処理。半分の解像度で計算してぼかす）

| 手法 | 中身 | 出典・考え方 |
|---|---|---|
| 光芒（ゴッドレイ） | 画素ごとに視線に沿って 32 点、日光の影の地図を調べ、日の当たる空気の散乱を足す。窓・柱の間から差す光の筋になる。前方散乱（光源の方を見ると強い）は Henyey-Greenstein | 影の地図を使う体積光の光線行進（Tóth & Umenhoffer 2009、Wronski 2014「Volumetric Fog」、Hillaire 2015「Physically Based and Unified Volumetric Rendering in Frostbite」） |
| 灯りのまわりの空気の光（グロウ） | 灯りごとに、視線が灯りの「照らす箱」の中を通る区間で、距離の 2 乗で弱まる光の散乱を**式で積分**（atan の差）。光線行進が要らず、16 個でも軽い。箱で切るので壁の向こうへ漏れない | 点光源の単散乱の解析解（Sun et al. 2005「A Practical Analytic Single Scattering Model for Real Time Rendering」） |
| スポットの光の円錐 | スポットライト（プラネタリウムの投影の光など）の円錐の中の空気を、光芒と同じ光線行進で明るくする | 体積光の光線行進（影なし） |

### 画面

| 手法 | 中身 | 出典・考え方 |
|---|---|---|
| 物の隅の暗さ（AO） | 深度と法線から、画素のまわり 12 点の遮りを数えて隅・物の接する所を暗く。深度を見てぼかす | McGuire 2012「Scalable Ambient Obscurance」 |
| しきい値の無いブルーム | 明るさのしきい値を使わず、7 段に縮めてぼかした画像を少し（8 %）混ぜる。明るい物ほど強くにじみ、光る面・光芒のまわりにグロウが出る | Jimenez 2014「Next Generation Post Processing in Call of Duty: Advanced Warfare」 |
| 自動露出 | 縮めた画面（1/32）の明るさの対数平均（中央を重く）から露出を決め、少しずつ慣らす（暗い所に入ると目が慣れる）。補正は EV | 目の慣れ（eye adaptation）。対数平均は Reinhard 2002 |
| トーン | Khronos PBR Neutral（色の濃さ・色相を保ったまま明るい所をなめらかに抑える）。場面の色調整は彩度・色相・色の偏りだけ残し、黒の持ち上げ・明度の段は止める。最初は AgX にしたが、AgX は明るい色を灰色に寄せ、場面の青緑・ミントの色が消えたのでやめた | Khronos「PBR Neutral Tone Mapper」 |
| 止める物 | クワハラ（絵の具のにじみ）・線（つまみで残せる）・ディフュージョン・画面のグラデーション（パラ・フレア） | 絵画的な仕上げの処理 |

## 2. 場面ごとの既定（`REAL_SCENES`）

場面のファイルは触らず、`src/render/Real.ts` の表で決める（パネルの「場面の既定に戻す」でこの値に戻る）。

| 場所 | 上書き | 理由 |
|---|---|---|
| 霧の駅・校舎の間・白いコンクリートの中庭・立方体の大広間 | 空気の濃さ 0.003〜0.005 | 屋外で日の当たる空気が長く続くと、光芒が一面の白い膜になる |
| 病院の病棟 | 日光 0.7・灯り 4 | 平行光源を天井の明かりの代わりにしている。灯り（照明器具）で照らす |
| 海の見える教室 | 光芒を調べる距離 9 m・露出 −0.2 | 窓の外（日の当たる海）の空気まで数えると窓が白く飛ぶ |
| サーバールーム・ウォーターパーク・プラネタリウム | 空気の光（グロウ）0.1〜0.25 | 灯りが多い室内で、部屋じゅうが白くかすむ |
| プラネタリウム | スポットの円錐 0.4・露出 −0.6 | 暗い劇場の暗さを残す |
| 淡色の廊下・校舎の間 | 塗りの材質の明るさ 0.7 | 照明を使わない塗りの場面（灯りの無い所の暗さを控えめに） |

## 3. 結果（2026-10-12）

- **切ったとき**: 元の 14 視点（`baseline-v1`）・2 つ目の組の 17 視点（`baseline-v2`）とも合格のまま。同じ撮り方の画像を画素で比べて、31 視点とも違う画素が無い（±2 の段まで）
- **入れたとき**（1456×816・1 フレーム）: 4.2〜9.1 ms。立方体の大広間だけ 8 ms を超える（8.2〜9.1 ms。屋外の長い光芒の光線行進と、窓の灯り 240 個）。塗りの照明より 0.5〜4.5 ms 重い
- 照明器具を灯りにした数: 病院 163・屋内プール 515・教室 70・サーバールーム 336・中庭 38・大広間 240（窓の明かり）・ウォーターパーク 587・プラネタリウム 182（霧の駅は器具が独自の光るシェーダーで 0、淡色の廊下・校舎の間は塗りで 0）。入れた時の 1 回だけ 0.1〜1.7 秒かかる
- 見え方: 屋内プール・中庭・大広間・教室は明暗比と日なたの形・光芒がはっきり出て写実寄りになった。サーバールーム・ウォーターパークは灯りと画面の光・ブルームが効く。プラネタリウムは暗さを残してスポットの光の円錐が出る

## 4. 残っている所・次に試せる手法

- **霧の駅**の照明器具は場面独自の光るシェーダー（`station/glow.ts`）なので、光る面の持ち上げ・器具の灯りが効かない（見た目の差が小さい）
- 場面ごとに独自のシェーダーで描いた所（ドーム・空・水面の一部など）は、リアルな照明の陰影を受けない
- 灯りに影が無い（照らす箱で壁の向こうへは漏れないが、家具の陰はできない）。次は近い灯り数個だけ影の地図（キューブの影）を持たせる
- 光芒は半分の解像度・32 点で、ぼかしで粒を消している。動くと少しちらつく所がある。次は前のフレームと混ぜる（時間方向のならし）
- 次に試せる手法: 画面の反射（SSR）・接地の影（コンタクトシャドウ）・レンズのにじみ（グレア・ゴースト）・霧を 3D の升目で持つ体積霧（froxel）・光の跳ね返り（SSGI）
