# 見た目の検証ステージ（visual-style-lab）

参考画像（imageboard の 14 枚）の見た目を 3D で再現し、その中を一人称で歩き回れるテストステージです。
ゲーム本体（v1 / v2）には一切影響しません（three だけリポジトリ直下の物を使います）。

結果（参考画像との色差 ΔE、小さいほど近い）: 淡色の廊下 2.4・病院の廊下 2.4〜2.8・通路 3.6・霧の駅 4.4〜5.2・屋内プール 6.6〜7.8。
詳しくは [docs/04-results.md](docs/04-results.md)。

## 公開（GitHub Pages）

v1 と同じ GitHub Pages の `lab/` の下に置きます（検索に出さないよう noindex）。v1 の公開を壊さないよう、gh-pages ブランチへ **追加**（`--add --dest lab`）で入れます。

```bash
cd experiments/visual-style-lab
npm run deploy:pages   # = vite build --base /pl-vs/lab/ → gh-pages ブランチの lab/ へ追加して push
```

- main と同じ中身を公開する（作業ツリーに他の作業の v2/ の変更があると、読み込んでいる v2 のカメラ効果に混ざるので、main を `git worktree` で出してそこから実行する）
- **v1 を `npm run deploy:v1` で公開し直すと gh-pages が入れ替わって lab/ が消える** → その後にこちらも公開し直す
- git は `/Library/Developer/CommandLineTools/usr/bin` の物を使う（Xcode の git はライセンス未同意で動かない）

## カメラ効果（VHS）

ゲーム（v1 / v2）の「描画効果」と同じ VHS カメラ効果を掛けられます。パネルの「カメラ効果（VHS）」か K キーで切り替え、設定はブラウザに保存されます。

| 項目 | 中身 |
|---|---|
| 描画効果 | オフ / クリーン / ホームビデオ / テープ（走査線・揺れ） |
| VHS 効果 | 0〜200%（ゲームの既定は 200%。100% でプリセットの値そのまま） |
| 元の色を残す | 0〜100%（既定 85%）。VHS の色調整（彩度低下・黄色寄りの白）・明部の潰れ・黒浮きで消える色を、元の映像の色へ戻す。走査線・揺れ・色のにじみと遅れ・ノイズ・トラッキング帯はそのまま。0% でゲームと同じ掛かり方 |
| 手持ち感 | 歩調の上下動・ロール・呼吸・ふらつき・ズームのゆらぎ（0〜100%） |
| 表示 fps | プリセットに従う / 30 / 24 fps に間引く |
| 視線の遅れ・REC 表示 | 50 ms の視線の遅れ、●REC とタイムコード |
| 露出の追従・色の追従 | 既定は切る（下の注意） |

URL でも指定できます（保存はしない）: `?view=station-1&film=tape&vhs=1.5&keep=0.85&handheld=0.6&hold=24`。撮影ツールも `--params 'film=tape'` で同じ。

- 効果の本体は v2 のファイルをそのまま読み込んでいます（`v2/client/render/LensPass.ts`・`VideoPass.ts`・`camera/CameraRig.ts`・`ui/RecOverlay.ts`。複製していないので、v2 で調整すればここにも届きます）。つなぎ込みは `src/render/Film.ts`。
- 後処理の中では、線と色調整を済ませた後（sRGB にする前）にレンズ → sRGB → ビデオの順で掛けます（線はレンズの歪みより前に描くので、歪んでも線と絵がずれません）。
- オフのときは、手持ち感・視線の遅れ・REC も止めます（参考画像との見比べの邪魔をしないため）。
- 「元の色を残す」は、v2 の VideoPass のシェーダーをこの検証ステージの中でだけ書き換えています（v2 のファイルは変えない）。色段の最後で、輝度は VHS の処理のまま、色差（Cb・Cr）を「にじませて遅らせた元の色差」へ戻します（黒浮きで明るくなった暗部は、その分だけ色差も増やす）。合わせて、強さ（上限を通した後の値）で色のにじみの幅を最大 4 割・黒浮きを 6 割・ニーを 5 割・行ごとの色相ずれを 5 割・四隅の減光を 5 割弱め、走査線は暗い行と明るい行を作って平均の明るさを保ちます。
  テープ・強さ 200% での色の濃さ（OKLab の彩度 ×100。効果なし → 今まで → 85%）: 駅 4.9 → 2.3 → 4.2、校舎の間 3.7 → 1.5 → 3.4、プール 5.3 → 3.3 → 4.5、病院 4.3 → 3.9 → 4.0、淡色の廊下 2.1 → 3.1（黄色へ寄る）→ 2.1
- この場面の色は表示の明るさのまま（白い壁で 0.8〜0.95）で、ゲームの暗い部屋（壁 0.3〜0.5）より明るいので、2 か所だけこの検証ステージの中で合わせています。
  1. レンズのにじみ: LensPass に渡す前に 0.5 倍して、後で戻す（光る板だけがにじむ）
  2. テープの明部の滲み（smear）: 始まる明るさを 0.55 → 0.9（白に近い所だけ。v2 のシェーダーはこのステージの中でだけ書き換え）
- 露出・ホワイトバランスの追従はゲームの暗い部屋向けの目標値なので、ここでは既定で切っています（入れると明るい場面が暗く、青緑の場面が灰色に寄ります）。

## 撮影と比較

```bash
cd experiments/visual-style-lab
node tools/capture.mjs all --sheet  # 全視点を 1456×816 で描き、参考画像と並べた画像・差の地図・色差、一覧 sheet.jpg を出す
```

タッチ操作（スマホ・タブレット）: 画面の左半分をなぞると移動、右半分をなぞると見回す。

結果は `scratch/captures/`（git 管理外）。

建築版は `--page arch.html` を付ける。間取り図 `--plan <場所>`・道順の撮影 `--tour <場所>`・歩いて行けるか `--reach <場所>`・元の版との比べ `--baseline tools/baseline-v1.json`（docs/06-architecture.md の 8 章）。
質感の物差し `--quality <場所> [--seed N]`（参考画像・視点の描画・道順・無作為の場所を同じ数値で比べる）・1 枚と数値 `--shot <場所> x,y,z,yaw,pitch`（docs/07-unseen-quality.md）。
