# v2 の小物の振り分け（モデル / スプラット）

v2 の中身の生成（`v2/core/gen/dress`）が置くすべての物を、「箱の組み合わせとテクスチャで作るモデル」と「スプラット」に振り分け直した表です。見本の部屋（`index.html`）と、v2 本体の作り込む小物（`v2/client/props`。設計は `v2/docs/props.md`）はこの表のとおりに作っています。

「スプラット」の物は、形の関数（`.claude/skills/procedural-3d-objects`）で作り込む物です。同じ形の関数から、スプラットか同じ形のメッシュのどちらでも描けます（見本の部屋は P で切り替え、v2 のゲームはメッシュ）。

## 振り分けの決まり

**モデル（v2 の箱のまま）にする物**
- 形が平らな面と直角の角でできていて、箱を組み合わせれば実物と同じ形になる物
- 見た目がテクスチャ（木目・塗装・金属・布の柄）で決まる物
- 例：棚、机、ソファ、ロッカー

**スプラットにする物**
次のどれかに当てはまる物。
- **曲面・丸い形**（円筒・球・円すい・くぼみ）が本体で、箱では別の物に見える
- **細かい物の集まり**（葉・毛・本の列・商品の列）で、1 つの箱にまとめると中身が分からなくなる
- **柔らかい物**（布・紙・ぬいぐるみ）で、しわ・たるみ・ふくらみが見た目の大半
- **透ける・光る小物**（ペットボトル・ガラスの瓶）で、形と透け方が見た目の大半

迷う物は「プレイヤーが近くで見る機会があるか」で決めました。近くで見る物はスプラット、遠くに並ぶだけの物はモデルです。

## 見本の部屋での確かめ方

- 見本の部屋（`index.html`）は v2 と同じ材質・照明・霧・ポスト処理・懐中電灯で作った 7 部屋です（展示ホール・書庫・売り場・寝室・トイレ・設備の部屋・持てる物の部屋）。置いた展示物の一覧は [README.md](README.md) にあります。
- モデルの物（棚の枠・机・ソファ・ベッドの枠・カウンター・台座・ショーケース・自販機など）は v2 の作り方そのまま、スプラットの物は上の表の作り方で置いています。
- 表のうち見本の部屋に置いていない物: 冷蔵ケースの中の商品（陳列棚の商品と同じ作り）、衣類、ペーパータオル。
- **P** で表示を「スプラット → 同じ形のメッシュ → v2 の箱」の順に切り替えて見比べられます。同じ形のメッシュは、スプラットと全く同じ形の関数から作った三角形とテクスチャを v2 の材質で描いたものです。v2 の箱は、v2 がいま置く箱の作り（棚の中身の色の箱・葉の箱・掛け布団の箱など）で、v2 に元の作りが無い物（ぬいぐるみ・ごみ箱の中身など）は同じ大きさの箱か、何も置きません。
- 右下のパネルの一覧から、展示物の前へ移れます（**N** / **B** で次・前）。

## v2 の世界での差し替え（v2 の client/props）

v2 は、区画の箱からこの表の「スプラット」の物を見つけ（`v2/client/props/plan.ts`）、形の関数のメッシュに差し替えます。「モデル」の物は箱のままです。異変が触った箱（`Box.odd`）とそれに触れる物も箱のままです（`v2/docs/props.md`）。

| この表の物 | 見つけ方（v2 の箱） |
|---|---|
| 植物 | `plant` の propGroup。高さで種類と大きさを決める。植え込みは `planter` |
| 本棚の本・ファイル・雑誌、棚の商品、冷蔵ケースの中 | 棚・冷蔵ケースの propGroup の中で、枠に囲まれた段の箱。売り場のテーマ・金属の棚・冷蔵ケース・缶のラベルの色なら商品、他は本・ファイル。段ボールの段はそのまま |
| 寝具・診察台の枕 | `bed` / `examBed` の上の布の箱 |
| 給水機のボトル | `waterCooler` の青い箱 |
| 展示物 | `plinth` / `vitrine` の上の箱。材質でトロフィー・彫刻・花瓶・ぬいぐるみ |
| カラーコーン・小便器・洗面器・便器・流し台・自販機の中 | それぞれの propGroup の箱の並び |
| 電気スタンド・壁掛け時計・壁の灯り・消火器・掲示の紙・布団・座布団・カーテン・リング・ボールプール | 箱の大きさ・材質・壁からの位置 |
| 持てる物 | v2 の持てる物の描画を、kind ごとの形の関数に差し替える（振る舞いは v2 のまま） |

差し替えないもの: 異変・部屋の仕掛けのある区画、隠し・ずれる・傾く箱、異変の小物、集める本の棚・写しの並ぶ所・崩れる山（v2 の別の描画が受け持つ物）。ごみ箱の中身・机や床の紙（v2 では異変の紙だけ）・タオル・トイレットペーパーは、v2 がいま置いていない（見本の部屋だけ）。
