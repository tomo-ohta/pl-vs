# v2 の小物をスプラットにする検証

v2 の部屋（構造・テクスチャ・焼き込み陰影・照明・霧・ポスト処理・懐中電灯）はそのままにして、**小物だけ**を作り直す検証用のページです。小物は「形の関数」（`.claude/skills/procedural-3d-objects` の作り方。部品と形の関数は `v2/client/props`）で作り、Spark の 3D Gaussian Splatting（見る向きで色が変わる SH 入り）か、同じ形の関数から作ったメッシュで描きます。ページは 2 つあります（v2 の世界で差し替える版は v2 本体へ移した）。

| ページ | 中身 |
|---|---|
| `http://localhost:5175/`（`index.html`） | **見本の部屋**。v2 と同じ雰囲気の 7 部屋に、作り込む物（64 点）を並べる。スプラット / 同じ形のメッシュ / v2 の箱を P で切り替えて見比べる |
| `http://localhost:5175/capture.html` | 前の検証: v2 の小物の箱を写し取ってスプラットにする（形は v2 の箱のまま） |

このフォルダの開発サーバーは v2 のソースを読むだけです（v2 のファイルは変えない）。ポートも保存領域も v2 と別です。

## 動かし方

リポジトリ直下で:

```bash
npm install --prefix experiments/v2-splat-props --legacy-peer-deps   # 初回だけ（Spark を入れる。three は v2 と同じものを使う）
npm run dev --prefix experiments/v2-splat-props                       # http://localhost:5175/
```

`.claude/launch.json` の `v2-splat-props` も同じです。v2 の開発サーバー（5174）と同時に動かせます。

`?rooms=service,carry` のように、作る部屋を絞れます（確かめるとき用。他の部屋は v2 の箱のまま）。

### 操作

v2 の操作はそのまま（「始める」で開始。Esc で一時停止するとマウスでパネルを触れる）。追加したもの:

| | |
|---|---|
| **N** / **B** | 次・前の展示物の前へ移る（右下のパネルの ◀ ▶・一覧からも） |
| **P** | 表示を順に切り替える: **スプラット → 同じ形のメッシュ → v2 の箱**（いまの v2 の作り）→ …（Shift+P で逆へ。パネルのボタンでも） |
| 右下のパネル | 展示物の説明と粒・三角形の数、FPS、部屋の作成の進み具合、スプラットとメッシュの GPU の量（計算値）、つやの強さ・粗さ・SH の段数（変えると色だけ計算し直す） |

### しくみ

1. **部屋**（`src/showroom/layout.ts`）: v2 の `makeCell`・テーマの配色・天井の照明と、v2 の家具の関数（`core/gen/dress` の棚・机・ソファ・ベッド・カウンターなど）で FloorLayout を作る。v2 を実験場の指定（`?lab=1`）で起動し、読み込み後にこのフロアへ読み替える（`src/showroom/main.ts`）
2. **形**（`v2/client/props/shape.ts`・`gen/*.ts`、粒は `src/showroom/surfel.ts`）: 展示物ごとに、曲面（回転体・楕円体・角の丸い箱・管・葉）の上に 2D ガウシアンを長さで等間隔に敷く。粒ごとに向き・大きさ・地の色・粗さ・金属度・不透明度・材質（つや消し・プラスチック・陶器・金属・透ける物）を持つ
3. **明るさ**（`src/showroom/light.ts`）: v2 の焼き込み照明（器具の配光・遮蔽・接触の陰）を粒ごとに当て、v2 の材質と同じ式で拡散を作る。点光源の鏡面反射・部屋の環境マップの映り込み・クリアコート（陶器の釉薬・ペットボトル）を 48 方向で計算して SH（3 段）にする（Worker）
4. **描く**: Spark の `SparkRenderer` を v2 の scene に入れ、霧と懐中電灯は粒ごとに照らし直す（`src/splatMaterial.ts`、写し取る版と共通）。ぬいぐるみ・鉢などの中には「深さだけを書く箱」を置き、GTAO（画面空間の遮蔽）が後ろの壁の隅の陰を粒に掛けないようにしている
5. **同じ形のメッシュ**（`src/showroom/meshes.ts`）: 形の関数を 1 回走らせる間に、曲面ごとに三角形の格子（頂点は粒の間隔の 2.5 倍）と、粒と同じ細かさのテクスチャ（地の色・不透明度・粗さ・金属度・光る分）も書き足す（`surfel.ts` の `recordMesh`）。部屋ごとにアトラスへ詰め、v2 の材質（`MaterialLibrary.adoptExternal` で焼き込み光・霧・色が抜ける異変などを注入した MeshStandard / MeshPhysical）で描く。頂点に v2 の焼き込み照明を焼き、点光源・懐中電灯・映り込み・GTAO は v2 の描画がそのまま掛ける。粒だけの表現（ぬいぐるみの毛羽）はメッシュには無い
6. **見比べ**: v2 が置く箱の作り（棚の中身の色の箱、植物の葉の箱、ベッドの掛け布団の箱など）を同じ部屋に隠して作っておき、P で出し入れする。v2 に元の作りが無い物（ぬいぐるみなど）は同じ大きさの箱

### 確かめたこと（Mac・Chrome 系・960×600・画素比 2）

- 粒は 7 部屋で約 443 万（展示ホール 78 万・書庫 115 万・売り場 92 万・寝室 48 万・トイレ 12 万・設備の部屋 44 万・持てる物の部屋 54 万）。同じ形のメッシュは三角形 約 124 万・テクスチャ 約 1,060 万画素
- 平らな面（本の背・箱の面・紙など、形が u・v の一次式の面）は、焼き込み光の分（25 cm おき）だけ頂点を置く（模様はテクスチャが持つ）。見た目は変わらず、三角形は持てる物の部屋で 19.9 万 → 14.7 万、v2 の世界の本の多い区切り（本の列 161）で 41.7 万 → 11.7 万
- 3 つの表示とも 120 FPS（この Mac の画面の上限。差は測れなかった）
- GPU に置く量（計算値・7 部屋）: スプラット 約 473 MB（1 粒 112 バイト。うち SH 64）/ メッシュ 約 186 MB（大半が圧縮していないテクスチャ）
- 作成の時間（部屋ごと）: 形の関数 0.1〜1.3 秒、同じ形のメッシュの曲面を足すと +0.1〜1.0 秒、メッシュの組み立て 0.02〜0.2 秒。スプラットだけに要る焼き込み 0.03〜0.4 秒と SH 0.2〜2.3 秒。全部で 15 秒ほど。作れた部屋から順に切り替わる（それまでは v2 の箱）
- 見た目: 本・商品・陶器・時計はメッシュの方が縁と文字がくっきりする。植え込み・小さな葉はメッシュだと細かくちらつき（エイリアス）、スプラットは柔らかい。ぬいぐるみはメッシュだと毛羽が無く、つるっとした布に見える。ガラスの奥の物はメッシュだと v2 のガラス（透過のぼかし）が正しく掛かる（スプラットはガラスの手前に描かれる）
- タブが裏にあると Worker が遅くなり、作成に数倍かかる

### 分かっていること・制限

- 形は手続き（コード）で作った物で、撮影データではない。写実感は形と模様の作り込み次第
- 透ける物（ペットボトル・ガラスの奥のクマ）は、v2 のガラスのメッシュとの前後が完全ではない（粒はガラスの色を受けない）
- 照明を消す仕掛け・色が抜ける異変など、後から変わる見た目は粒に反映されない（懐中電灯だけは照らし直す）
- スマホは未確認（粒が多いのでメモリが心配。SH の向きの数は減らしてある）

## v2 の世界で小物を差し替える（v2 本体へ移した）

前は `world.html` で、v2 のファイルを変えずに小物を形の関数のメッシュへ差し替えていた。2026-10-06 に v2 本体へ移した
（`v2/client/props`。設計と数は `v2/docs/props.md`）。ふつうに v2 を遊ぶと小物が形の関数の物になり、`?props=0` で箱のまま、
見本・`?dev=1` では P で切り替える。形の部品と形の関数（`shape.ts`・`gen/*.ts`）も v2 本体が正で、この見本の部屋はそれを読む。

## 写し取ってスプラットにする版（capture.html）

前の検証です。v2 の世界をそのまま遊び、v2 の小物の箱を写し取ってスプラットにします（形は v2 の箱のまま）。

- `http://localhost:5175/capture.html` … 小物がスプラット
- `http://localhost:5175/capture.html?splat=0` … 素の v2（同じサーバーで見比べる用）
- v2 の URL の指定（`?seed=` `?floor=1` `?showcase=1` `?nolock=1` など）もそのまま使えます

### 操作

v2 の操作はそのまま。追加したもの:

| | |
|---|---|
| **P** | スプラット ↔ v2 のメッシュを切り替え（同じ場所で見比べる） |
| 右下のパネル | つやの強さ・粗さ・SH の段数、粒の大きさ・まとめ方・変える半径、植物の葉の粒。Esc で一時停止するとマウスで操作できる |

パネルの「つやを強調」で、つや（鏡面反射・映り込み）を 2.5 倍・粗さを半分にします。「v2 と同じ」で v2 の材質どおりに戻ります。

#### URL で変えられる値

| 値 | 意味 | 初期値 |
|---|---|---|
| `?radius=18` | スプラットにする半径（m、カメラから区画の外形まで） | 18（スマホ 12） |
| `?texel=0.01` | 細かい粒の大きさ（m） | 0.01（スマホ 0.015） |
| `?budget=2500000` | スプラットにした区画の粒の合計の上限 | 250 万（スマホ 80 万） |
| `?gloss=1` `?rough=1` | つやの強さ・粗さの倍率 | 1・1 |
| `?sh=3` | SH の段数（0 = 見る向きで変わらない） | 3 |
| `?leaves=0` | 植物の葉を箱のままにする | 葉の粒にする |

### しくみ

1. **小物を選ぶ**（`src/props.ts`）: v2 の中身（`core/gen/dress`）が `propGroup` を付けた家具・設備約 45 種（机・椅子・棚・ソファ・ロッカー・自販機・便器・植物…）。柱・飾りの扉・非常口の表示・異変や仕掛けの部品は対象外。ガラス・水などの透明な箱は v2 のメッシュのまま。
2. **区画を作らせる**（`src/manager.ts`）: 小物の箱に「この検証専用の印（revealGroup）」を付けた写しで v2 に区画を作らせる。部屋は v2 と同じメッシュで、焼き込み陰影・ライトマップの遮蔽にも小物はそのまま入る（床に落ちる陰は v2 と同じ）。小物は小物ごとの隠れたメッシュとして受け取る。当たり判定は元の区画のまま。
3. **色を写し取る**（`src/capture.ts`）: 小物の箱 1 つずつを v2 の材質のまま 6 方向から平行投影で撮る（箱を画像の上に並べて 1 方向 1 回）。v2 の材質の診断表示を使って、ふだんの見た目・地の色・粗さの 3 枚を撮る。
4. **粒を作る**（`src/facegen.ts`）: 箱の面に 2D ガウシアン（面に貼り付いた楕円の粒）を敷く。色の揃った所は大きな粒にまとめ、壁・床・他の箱に接して見えない面は作らない。植物の葉の箱は、箱の中に向きばらばらの葉の粒を散らす。
5. **見る向きで変わる色**（`src/sh.ts`、Worker で計算）: v2 の材質と同じ式（three の GGX・環境マップの映り込み・クリアコート・v2 の頭打ち）で、点光源の鏡面反射と部屋の環境マップの映り込みを 48 方向で計算し、SH（3 段）に合わせる。環境マップは v2 の部屋ごとの PMREM をそのまま読み出す（`src/env.ts`）。
6. **描く**: Spark の `SparkRenderer`（色は半精度で HDR のまま）を v2 の scene に入れる。v2 と同じ霧を掛け、懐中電灯（動く光）は Spark のシェーダで粒ごとに照らし直す。小物のメッシュは「深さだけを書く代役」として残し、GTAO（画面空間の遮蔽）・レンズの深度が正しくなるようにしている。

近くの区画から 1 つずつスプラットにし、遠ざかった区画・粒の合計が上限を超えた分は v2 のメッシュへ戻します（メモリを抑えるため）。変換中の区画は v2 のメッシュのままです。

### 確かめたこと（Mac・Apple M5・Chrome 系）

- v2 のメッシュと並べると、色・明るさ・陰はほぼ同じ（懐中電灯あり・なしとも）。粒の縁が少し柔らかい
- 1 区画の変換は 0.1〜2.5 秒（粒 100 万の区画で約 2.4 秒。写し取り 50〜260 ms・粒 10〜400 ms・残りが SH）
- 区画 10 個・粒 170 万で描画は軽い（このページの描画 1 回あたり 2〜4 ms。v2 のメッシュの小物と同程度）
- 植物は葉の粒にすると、v2 の「葉の模様の箱」より茂みらしく見える

### 分かっていること・制限

- **形は v2 と同じ箱のまま**。スプラットの写実感は撮影データの形の細かさから来る部分が大きく、この検証は「v2 の小物をスプラットで描くとどう見えるか」「部屋になじむか・重さ」を確かめるもの（植物の葉の粒だけは形を変えている）
- 写し取った見た目は変換した時点のもの。照明を消す仕掛け・色が抜ける異変など、後から変わる見た目は粒に反映されない（懐中電灯だけは照らし直す）
- 環境マップの映り込み・点光源の鏡面反射は SH（3 段）なので、鋭いハイライトはぼやける（撮影データの 3DGS と同じ性質）
- スマホは未確認。粒の合計の上限・半径を小さくしてあるが、半精度の粒と SH はメモリを多く使う
- タブが裏にある・描画が重いときは変換が遅れる（その間は v2 のメッシュ）
