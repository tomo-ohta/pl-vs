# V03 第2回：木目方向・面取りUV・反復抑制

2026-09-16 / 実装識別子 `v03-macro1`

## 今回完了した範囲

1. **面取りUV**: BoxGeometry / RoundedBoxGeometryの面グループを使って投影方向を固定。補間法線が45度をまたいだときに、一つの面の途中でUV投影面が切り替わる問題を防ぐ。
2. **木目方向**: 扉と縦木枠は縦方向、横木枠・巾木は長手方向、木床は敷設方向。全体を回転配置してもメッシュと一緒にUVが回転する。
3. **チャンク接合**: UV原点は室内座標で維持。描画チャンクに分割しても、同じ壁面上の接合点のUVが一致する。
4. **反復抑制**: 壁紙・カーペット・コンクリートのカラー画像を、向きを変えず2箇所から採取し、約4.5mスケールの連続的な分布で混合。色は最大約±4%、粗さは最大約±0.02の変化を重ねる。実際の分布幅はノイズ値に依存する。
5. **再現性**: 時間と世界生成RNGを使わず、部屋ローカル座標だけで分布を決める。追加画像、当たり判定変更、ワールド生成・セーブ形式変更はない。
6. **互換性**: 木目・タイル目地・サイン・空・発光体・水面には反復混合を適用しない。legacy / untextured表示を除外。既存の色欠損、濡れ具合、勾配、部屋別霧の処理を残す。

これはV03の「UVと反復抑制」の完了であり、V03全体の完了ではない。

## 第4回：壁際の埃・水際の湿気（2026-09-16）

### 実装

- C02の単一矩形の床で、長辺の壁際0.025〜0.24mに埃マスクを追加。床上面だけに適用し、固定seedのムラを重ねる。色は最大12%明るく、粗さは最大0.12増やす。歩行帯の摩耗とは独立して合成。
- R01は従来の一律wetness=0.3と濃色の薄い壁帯を置き換えた。`wetWallBoxes` が実際の `waterShallow` 箱と接するタイル壁を抽出し、水がある区間だけ描画用に分割する。乾いた前庭／穴の区間は水面矩形に従って除外。元の壁座標・UVを維持し、追加の帯面を重ねない。
- 湿潤マスクは実水面の高さを基準に約0.015〜0.16m上で減衰し、境界に最大±0.035mのムラを加える。色を最大23%暗くし、既存roughnessを0.2へ最大85%近づける。既存のPBR照明・環境反射に反応するが、新しい鏡面反射パスや屈折処理はまだ追加していない。
- `ShallowWater.ts` の局所濡れ対応はR01限定。R14/L02等は既存の一律補正を維持。明示された他のwetness指定は消さない。水面・水ゾーン・水深・扉前庭・減速・衝突判定は変更しない。
- `surfaceEnvironment` vec4属性を追加（通常boxと扉に16 bytes/vertex追加、前回の属性と合計36 bytes/vertex）。部屋固有の材質複製や追加テクスチャは不要。レガシー・無テクスチャ・横倒し空間は適用除外。
