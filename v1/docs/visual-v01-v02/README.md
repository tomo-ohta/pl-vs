## V02：独立した表面データと素材区分

- 元の12画像系統すべてとskyに、albedoから独立した表面データを用意。追加のpaint/rubber/glassを含め16系統。8系統で残っていた「カラー画像を凹凸と粗さへ複製」を廃止。
- `SurfaceDetail.ts` が周期的微細構造から、height（R）、相対roughness（G）、専用tangent normal、専用micro-AOを作る。模様や汚れのRGBを高さとして読まない。
- normalは周期境界で中央差分を取り、OpenGL +Y。材質の凹凸振幅/実寸でnormalScaleを指定。AOは微細な窪みのみで最大14%、独立Rマップ、UV channel 0。three 0.186の `aomap_fragment` がRを読み、`Texture.channel=0` がuvを使うことをローカル実装で確認。
- カラーはsRGB、法線・roughness・AOはNoColorSpace。実際の描画はnormalMapを用い、bumpMapを二重に掛けない。旧roughness圧縮処理は削除。
- 塗装扉・塗装棚・車体・ガラス・ゴムは非金属。露出金属 `metal` は0.94。塗装を貫く金属傷は今回は作らず、不要なmetalnessMapはnull／定数で扱う。
- 車窓・ガラス・暗い窓に金属カラー画像を貼らない。専用の平滑な表面データとMeshPhysicalMaterial（transmission=.85、IOR=1.5、thickness=.012m）。車体は非金属塗膜＋clearcoat=.85、clearcoatRoughness=.16。
- 水面のアニメーションUVを旧bumpMapからnormalMapへ移行。legacyで法線マップが無い場合にもシェーダーが成立するよう条件分岐した。
- 58素材のID、実寸、tint、UV方針、マップ、色空間、画像生成プロンプト、派生方法、定数値を [material-manifest](../../assets/material-manifest.json) に記録。
- カラー画像は従来のimage_gen資産を継続利用。今回は新規カラー画像を生成していない。派生マップは意図した微細構造の近似で、実測PBRスキャンではない。

- [白色](materials-white.png)、[暖色](materials-warm.png)、[斜め光](materials-raking.png)：非金属の広い反射、金属の鋭い反射、木・紙・繊維の粗さ差を確認。
- [鏡像UVの法線](materials-mirrored-normal.png)、[鏡像UVの通常表示](materials-mirrored-beauty.png)：UVを中央で反転しても面全体の法線反転や黒い継ぎ目が出ないことを確認。微細ノーマルの+Y符号と周期境界は数値テストでも検証。
- 32枚を一覧で目視確認。画像差だけを合否にせず、素材の識別、意図しない凹凸、接写対象、UV方向、明暗の破綻を確認した。
- 全58素材×7override=406コンパイル、shaderエラー0。型チェック・本番ビルド・16系統のデータテスト・既存のUV/seed/摩耗テスト成功。従来の大容量chunk警告は残る。
