# 全マップの素材・照明刷新

## 作業計画

1. 最新の6 GeneratorとAdapter、全MatIdの使用箇所を確認する。
2. 画像生成でシームレスな実写調素材を制作し、プロジェクトに保存する。
3. 全材質をPBRへ置換。実寸UV、凹凸、粗さ、金属反射、環境反射を設定する。
4. 生成済み形状を保ちながら、扉枠・巾木・照明枠・家具の面取りなどを整える。
5. 生成形状に合わせた静的陰影と光の分布、制限付き動的光、露出を統合する。
6. 全118定義（未実装生成器の代替表示を含む）を生成・材質検査し、6 Generatorの代表画像と複数品質で確認する。

## 方針

- 既存のレイアウト、接続、操作、セーブ構造を維持する。
- 画像生成は組み込みimage_genを使用。生成画像を共有し、色の差は材質で付ける。
- カラー画像からの凹凸・粗さ推定は計測済みPBRデータではない。小さな表面ディテールとして使用し、素材別の強度と解析的な目地で補う。
- 画面全体を強いノイズで隠さず、素材と照明を品質の中心とする。
- 実機スマホ性能は別途実機確認が必要。

## 実装結果

- 組み込み image_gen で12種類の画像を生成。壁紙、カーペット、コンクリート、木目、天井吸音材、タイル、金属、リノリウム、段ボール、葉、照明拡散板、水面。
- 生成原本: `assets/texture-source/`。実行用JPEG: `public/textures/liminal/`（合計約7.1MB）。完全な生成プロンプト: [prompts.json](../public/textures/liminal/prompts.json)。
- 全38 MatIdをMeshStandardMaterialで定義。色はsRGB、凹凸・粗さは非カラーとして処理。実寸UV、異方性フィルタリング、素材別粗さ・金属度、PMREM環境反射、天井と床の目地、水面の微動を実装。
- 扉の面取り・ノブ・枠、巾木、照明器具の枠、机の脚、開放棚、収納前板、段ボールの継ぎ目、車体・タイヤの簡易形状を追加。元の箱から当たり判定を作るため、細部の見た目と当たり判定には差がある。
- 面の向き・距離・遮蔽から生成時に照明を計算。接触部の陰影を付加し、近傍の点光源と環境照明を合成。ACESトーンマッピング、露出、霧を調整。
- 起動時に共有テクスチャの読み込みを待機し、読み込み失敗時は開始画面に通知。

## 現在の限界と次の品質向上

- 照明は静的な近似と点光源。実測PBR、経路追跡GI、部屋固有のリアルタイム反射ではない。
- 車両・植物・一部家具は簡略形状で、全オブジェクトがプロ品質の写実表現に達したとは評価していない。次は代表室を基準に輪郭、接地、局所的な汚れの分布を磨き込む。
- テクスチャの反復はミラーリピートと実寸UVで緩和しているが、大面積の繰り返しは残る。KTX2圧縮は未導入。
- 古さは素材の色調と経年表現を中心に出している。VHS/CRTの画面効果は今回未追加。素材・照明を評価した後、調整可能な弱い撮像ノイズ等を追加する余地がある。
